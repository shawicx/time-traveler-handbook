# Knowledge Base

The **Time Traveler Handbook** is an open-source knowledge base for time travelers.
Markdown is the single source of truth; the knowledge graph, timeline, and tech tree
are generated at build time, producing a fully static site.

Pick an era to enter — people, events, and technologies are aggregated within each
era page:
