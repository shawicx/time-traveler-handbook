## 一、时代概览

| 项 | 概况 |
| --- | --- |
| 时间 | 约公元前 1046 – 前 256 年（战国乱局本身延续到前 221 年秦统一） |
| 分段 | 西周（前 1046–771）· 春秋（前 770–476）· 战国（前 475–前 221） |
| 地域 | 黄河、长江流域；都城镐京（西周）→ 洛邑（东周，今洛阳） |
| 政体 | 分封制 + 宗法制；天子共主地位由盛而衰，战国走向集权官僚制 |
| 经济 | 井田制渐解、土地私有萌芽；春秋晚期起铁器牛耕；战国金属铸币流通 |
| 文字 | 金文、大篆、六国古文各异形；竹简典册普及，文字下移至士人 |
| 金属 | 青铜礼乐延续巅峰，生铁铸造（春秋晚期）为世界最早 |

武王于前 1046 年牧野克商，周公制礼作乐、营建洛邑，封建亲戚以屏周。前 841 年国人暴动、共和行政——**中国精确纪年自此开始**。前 771 年幽王死于犬戎，平王东迁，天子衰而为傀儡：春秋五霸"尊王攘夷"，战国七雄变法混战，至前 256 年秦灭周（战国之乱延续到前 221 年秦并六国）。

## 二、穿越前必须知道

- **先判断落在哪一段**：西周是礼乐严整的秩序世界；春秋是贵族车战、讲信修睦又争霸的时代；战国是编户齐民、总体战与变法的乱世。生存策略三段完全不同（见下文各节标注）。
- **人祭废除了**：周礼以"敬德保民"取代商代血祭，你不再有被送上祭坛的系统性风险。但贵族人殉残存（秦穆公殉葬一百七十七人），仍不可掉以轻心。
- **阶层开始流动**：士阶层崛起，战国养士成风（孟尝君门下食客三千）——"仅凭头脑吃饭"在这个时代首次成为正经职业路径。
- **文字下移了**：竹简书籍流通，识字可以谋生。篆书与你认识的汉字有清晰谱系关系，学习门槛远低于甲骨文。
- **铁与牛改变一切**（春秋晚期起）：生产力跃升，人口、城市、战争规模同步膨胀。
- **有真医生了**：巫医开始分离，扁鹊式的职业医者出现（春秋末至战国）。你的医学优势仍在，但对手从占卜师变成了原始经验医学。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定落点与分期**：看三样东西——军队（车战披甲贵族 = 春秋；步骑混编、弩机上弦 = 战国）、货币（贝与青铜块 = 西周；布币刀币圜钱 = 战国）、城邑（小邑 = 西周；临淄式大都会 = 战国）。判断错误，后续每一步策略都会错。
2. **先解决水**：规矩不变——**必须煮沸**。借陶器与火种，无陶器则沙坑渗滤或竹节烧水。
3. **解决衣物**：麻皮、兽皮裹身，尽快换成当地常服。周人重礼，衣冠即是身份语言——穿得像个"庶人"，比穿得古怪安全得多。
4. **依附一个邑**：入"国"（城）投手工作坊或人家为佣，在野则投乡邑。战国可考虑投奔养士的卿大夫门下，但初来乍到，先以苦力与手艺立足。
5. **编好身世**：周人问"族何姓、何国人"。西周春秋答"失其族籍的流亡庶人"，战国答"没落士人之后"——能诵几句《诗》佐证，比任何解释都管用。

## 四、第一个月

- **学雅言**：士以上的通用语。第一个月目标：听懂指令、报出身世、说出诉求。
- **掌握一门营生**：农（需求最大）、工（陶、骨、织）、商（战国活跃）皆可。识字者可求做书吏学徒（战国需求旺盛）。
- **观察权力结构**：诸侯—卿大夫—家臣宰，层层有靠山。战国更要看清变法派与守旧派——站错队会死。
- **储备过冬**：北方冬季依旧致命，秋天囤粟囤柴。封火、草被、防湿见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"游方医者"**：巫医已分离，行医是正当营生（战国尤甚）。你不再需要与神职集团争夺解释权，只需融入当时的话语体系（阴阳、六气）。

| 层级 | 角色 | 你的处境 |
| --- | --- |
| 天子 | 周王，名义共主（东周起实权归零） | 不可接触 |
| 诸侯 | 公侯伯子男，封国君主 | 春秋需取悦，战国是赌局 |
| 卿大夫 | 封邑领主、执政世家 | 你真正的天花板 |
| 士 | 文武兼习的最低贵族层 | **你的上升通道** |
| 国人 | 城邑平民（工商） | 你的起点身份之一 |
| 野人 | 乡野庶民、井田耕者 | 你的起点身份之二 |
| 奴隶 | 数量与地位远低于商代 | 避之即可 |

**西周身份凝固，战国剧烈流动**。商鞅变法后的秦，军功爵面前人人可爬；稷下学宫前的齐，一张嘴可以换到大夫之位。你的现代知识在战国是硬通货——但也正因如此，越是动荡的国度，越要掂量"显眼"的代价。

## 六、语言与交流

- **语言**：上古汉语，士以上通行"雅言"，各地"言语异声"（战国尤甚）。落地先学所在国的方言，再修雅言。
- **文字**：金文 → 大篆 → 六国古文（字形各异，秦统一后才书同文）。你认识的汉字（尤其繁体）与篆书同源，**认读门槛远低于甲骨文**；书写用毛笔与竹简，习字可谋生。
- **《诗》是社交货币**：春秋外交与贵族宴飨讲究"赋诗言志"——能恰当引用《诗经》，立刻会被当作受过教养的人。出发前背熟一二十则名句。
- **数字与算筹**：筹算通行，十进位值制熟练者被视为能吏。你的心算与速算可碾压。
- **可学的基础词**：沿用夏商方案——水、火、食、人、来、去、好、坏，先记语义后抠发音。

| 类别 | 内容 |
| --- | --- |
| 主食 | 北粟南稻，麦渐普及；战国产量因铁犁牛耕大增 |
| 平民餐 | 豆饭藿羹、粟粥、腌菜；肉食罕至（"肉食者"即贵族） |
| 贵族餐 | 八珍之味、鼎食钟鸣 |

**关键生存知识**：战国城市密集，疫病随人口聚集而起。识别可食野菜（荠、藜、蕨）依旧是荒年保命技能——识别要点与试探程序见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：上衣下裳、深衣渐兴；麻为主体、丝为贵。周礼以衣冠别尊卑——**穿对衣服就是半堂礼仪课**。
- **冠带**：士以上加冠，庶人裹巾。你以庶人身份活动时切勿僭越冠服。
- **住**：西周出现瓦顶，战国民居仍以夯土、木构、草顶为主。大都会（临淄、邯郸、大梁、郢、咸阳）人口以十万计，市肆连片。
- **寝**：草垫、苇席。虱蚤依旧——接受它。

## 九、健康与医疗

**对手变了：不再是占卜师，而是原始经验医学。你的优势依旧碾压。**

- **真医学已萌芽**：医和提出"六气"致病，扁鹊立望闻问切四诊、《周礼》有食医疾医疡医之分科。他们是对手，也是你的话语外壳——**用阴阳六气解释你的消毒与隔离**，比用"细菌"有效一万倍。
- **卫生知识仍是神迹**：煮沸饮水、清洁伤口、隔离病患、焚烧疫尸。战国的城市密度让这些比商代更值钱。
- **战地急救是战国硬通货**：止血带加压、夹板固定、创面清洁、烧伤护理——总体战时代，各国军队都缺这类人。这是你从庶民跃升的最快路径，也是把你推向前线的原因，取舍自慎。
- **草药**：艾草、车前草、蒲公英的"带脑子药箱"方案不变，识别要点见[生存技能实操](/zh/guides/survival-skills/)。
- **心理**：商代的恐怖来自祭坛，周代的恐怖来自战场——长平之战据记载坑降卒四十余万（数字有争议，规模空前）。出发前完成对大规模尸骸场景的脱敏（[心理建设与脱敏](/zh/guides/mental-preparation/)）。
- **分娩与牙病**：洗手助产、沸煮切割工具、柳枝洁齿——核心价值筹码不变。

## 十一、法律与信仰

- **从礼到法**：西周"明德慎罚"、以礼治国、无成文法；前 536 年子产铸刑书，成文法时代开启；战国《法经》与商鞅之法刻薄寡恩、连坐肉刑并举。
- **信仰**：天命观——"天命靡常，惟德是辅"；祖先祭祀与社稷之礼并行。龟卜蓍筮（周易）仍在，但已非万事前置程序。
- **人殉残存、人俑渐兴**：贵族墓仍有人殉（秦穆公、曾侯乙墓皆然），但以俑代人渐成趋势。你无力阻止个例，保持平静即可。
- **周礼是行为法典**：列鼎制度（天子九鼎八簋、诸侯七、大夫五、士三或一）、丧服五服，礼仪僭越是政治罪。**记住自己身份对应的礼数，永远低半格行事。**
- **你的位置**：医、卜、星、相在周代皆可公开执业；战国"百家争鸣"，你甚至可以自成一派——但在法家当政之国（尤其秦），慎言慎行，勿做靶子。

## 十二、经济与贸易

- **货币进化三级跳**：西周仍用贝与青铜块；春秋晚期空首布出现；战国布币、刀币、圜钱、楚之蚁鼻钱与金版（郢爰）全面流通——**记住各国币制**是落地即用的技能。
- **商业繁荣**：子贡结驷连骑、范蠡三致千金，战国大都会"挥汗成雨"。商旅可带你穿越国境，是合法流动的通道。
- **盐铁是战略物资**：管仲"官山海"开盐铁之利，邯郸、宛等地冶铁成业。你可以凭地理记忆找到盐源、教人煮盐；**铁与弩是军工，秦国境内私碰即死**。
- **你的交换价值**：医术 > 农技 > 水利工程 > 识字书吏 > 苦力。水利工程知识（分流、排沙、淤灌原理）在战国是国之重器——韩国水工郑国以间谍身份为秦修渠，反成万世之利，可见其价。
- **硬通货**：黄金（楚金版）、铜币、布帛、盐。乱世之末，粮食与盐最实。

## 十四、科技水平

- **铁**：西周末见块炼铁，春秋晚期掌握生铁铸造（世界最早），战国铁农具普及。
- **牛耕**：春秋战国推广，与铁犁配合引发农业革命。
- **水利**：邗沟（前 486）、都江堰（前 256）、郑国渠（前 246，周亡后）——筑坝、分流、排沙皆有大成。
- **青铜**：礼乐转向日用与货币；曾侯乙编钟（前 433）一钟双音、失蜡法铸造登峰造极。
- **天文**：二十八宿体系成形（曾侯乙漆箱已见宿名），《春秋》录日食三十七次、前 613 年记哈雷彗星，甘德、石申编星表（世界最早之一）。
- **数学**：筹算、十进位值制、分数运算、勾股测量的《考工记》工程标准。
- **医学**：四诊、分科、六气致病说——理论化的开端。
- **军事**：车战（春秋）→ 步骑混编（战国）；青铜弩机、长城（楚方城、齐垣至战国各长城）。
- **书写**：毛笔竹简、帛书；百家著述，"学富五车"自此可期。

## 十五、现代知识优势

以下是你"知道但周人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生与防疫**：煮沸、隔离、焚疫尸。战国的城市密度让流行病学常识第一次有了用武之地。
- **农学**：垄作、轮作、堆肥、选种，配合铁犁牛耕，足以让一个县"粟支数年"——这正是各国变法求之不得的东西。
- **水利原理**：分流排沙、弯道环流、淤灌肥田。都江堰式的"深淘滩低作堰"原则你可以提前百年落地。
- **战地急救**：止血、固定、清创、烧伤护理——总体战时代的稀缺技能。
- **天象与历法**：太史局已有甘石级别的对手，你的优势从"独一份"变为"精度碾压"——**策略改为以历法家身份合作，而非斗法立威**。
- **数学与测量**：心算速算、几何测量、统计记簿，在任何官署都是即战力。
- **《诗》与仪礼**：背熟的名句与礼数是你初来乍到最便宜的通行证。

**严禁炫耀的知识**：弩机与冶铁改良（军工资敌，秦法处死）、法家权术表演（翻车极快）、"天下将归于秦"之类的预言（妖言罪）。

## 十六、出发前要记住的（检查清单）

这不是物品清单——你什么都带不了。这是**出发前必须装进脑子的知识与技能**：
