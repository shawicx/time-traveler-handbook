## 一、时代概览

| 分段 | 时间 | 去处 |
| --- | --- | --- |
| 西周 | 前 1046 – 前 771 | **本页**（礼乐秩序的世界） |
| 春秋 | 前 770 – 前 476 | [[spring-and-autumn-period|春秋]]页（贵族的黄昏、霸主政治） |
| 战国 | 前 475 – 前 221 | [[warring-states-period|战国]]页（总体战与百家争鸣；周亡于前 256，乱局延续到前 221） |

| 项 | 西周概况 |
| --- | --- |
| 地域 | 黄河、长江流域，都城镐京（今西安附近），东都洛邑 |
| 政体 | 分封制 + 宗法制："封建亲戚，以蕃屏周" |
| 经济 | 井田制；贝币与青铜块；手工业为王室与贵族服务 |
| 文字 | 金文、大篆；文字垄断于祝史卜人 |
| 金属 | 青铜礼乐鼎盛；西周末见块炼铁 |

武王于前 1046 年牧野克商，周公制礼作乐、营建洛邑，封建亲戚以屏周。厉王暴虐，前 841 年国人暴动、共和行政——**中国精确纪年自此开始**。前 771 年幽王死于犬戎，西周亡；次年平王东迁，天子渐成虚位。

## 二、穿越前必须知道

- **先判断落在哪一段**：西周是礼乐严整的秩序世界；春秋是贵族车战、讲信修睦又争霸的时代；战国是编户齐民、总体战与变法的乱世。三段策略完全不同——落地判别法见两页 era 页。
- **人祭废除了**：周礼以"敬德保民"取代商代血祭，你不再有被送上祭坛的系统性风险。但贵族人殉残存，仍不可掉以轻心。
- **一切依"礼"运转**：西周没有成文法，礼就是行为法典——衣冠、鼎数、揖让、称谓皆有等差。**按低半格的身份行礼**是铁律。
- **身份凝固**：你的出身决定你的终点。上升通道要到春秋末私学兴起、战国军功爵开闸才真正打开。
- **文字被垄断**：金文与大篆只属于祝、史、卜人。识字在西周是稀缺特权。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定落点**：秩序井然、无诸侯相攻 = 西周；会盟争霸 = 春秋；变法混战 = 战国。落错判断，策略全错。
2. **先解决水**：规矩不变——**必须煮沸**。借陶器与火种，无陶器则沙坑渗滤或竹节烧水。
3. **解决衣物**：上衣下裳、束发右衽，尽快换本地麻衣。周人以衣冠别尊卑，穿得像个"庶人"最安全。
4. **依附一个邑**：以"失其族籍的流亡庶人"身份求入邑。周人重族姓，但西周中期以后役梢频繁，邑中永远缺人手。
5. **不谈来历**：编好族源故事——周人问"族何姓、何国人"，答"避戎狄之乱，失了族籍"。

## 四、第一个月

- **学雅言**：士以上的通用语。第一个月目标：听懂指令、报出身世、说出诉求。
- **掌握一门营生**：农（需求最大）、工（陶、骨、织）。西周无自由商业可言。
- **观察权力结构**：诸侯—卿大夫—家臣，层层有靠山；邑中管事的是"宰"。
- **储备过冬**：北方冬季依旧致命，秋天囤粟囤柴，见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"懂医的庶人"**：以医术与手艺立足。西周医巫未分，你的消毒与隔离会被当作某种"祝由"，低调行事即可。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 天子 | 周王，真正的天下共主 | 不可接触 |
| 诸侯 | 公侯伯子男，封国君主 | 需取悦 |
| 卿大夫 | 封邑领主 | 你的天花板 |
| 士 | 最低贵族层 | 羡慕即可 |
| 庶人 | 国中与野外的劳作者 | **你的起点身份** |
| 臣妾 | 家内奴隶、隶臣 | 避之即可 |

**西周身份凝固**：庶人几乎无法变身为士。你的目标不是上升，而是成为"某邑受保护的医者/工匠"。上升通道要到[[spring-and-autumn-period|春秋]]（私学萌芽）与[[warring-states-period|战国]]（布衣卿相）才依次打开。

## 六、语言与交流

- **语言**：上古汉语，士以上通行"雅言"，各地"言语异声"。落地先学本地话。
- **文字**：金文（铸于青铜器）与大篆；识读垄断于祝、史、卜人。你的汉字底子与篆书同源，可自学但无处施展——**识字在西周换不来饭吃**。
- **礼是通用语言**：揖让、称谓、宴飨次序——比说话更重要的是不出格。
- **数字**：算筹通行，十进制成熟。
- **可学的基础词**：水、火、食、人、来、去、好、坏——老规矩。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 北粟南稻，麦渐普及 |
| 平民餐 | 豆饭藿羹、粟粥；肉食罕至 |
| 烹饪 | 蒸、煮、烤、腌渍——**无炒菜**（铁锅要到宋代） |
| 酒 | 祭祀与贵族宴飨用，庶人少沾 |
| 饮水 | **必须煮沸** |

**关键生存知识**：识别可食野菜（荠、藜、蕨）依旧是荒年保命技能——识别要点与试探程序见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：上衣下裳；麻为主体、丝为贵。周礼以衣冠别尊卑——**穿对衣服就是半堂礼仪课**。
- **住**：夯土基址、木构草顶；贵族瓦屋始见于西周。住在邑内，不要独居野外（戎狄与猛兽）。
- **寝**：席地而卧，铺垫草席。虱蚤如常——接受它。

## 九、健康与医疗

**西周医巫未分——你的知识将以"祝由"的面目流传。**

- **卫生知识仍是神迹**：煮沸饮水、清洁伤口、隔离病患。低调做出效果，不解释原理。
- **草药、助产、洁齿**：方案与夏商相同，识别要点见[生存技能实操](/zh/guides/survival-skills/)。
- **心理**：人祭已废，西周秩序下的血腥场面有限（祭祀用牲、刑戮）。心理压力主要来自严苛的礼与劳役，脱敏要求低于商与战国。仍建议过一遍[心理建设与脱敏](/zh/guides/mental-preparation/)。
- **职业医学要到[[spring-and-autumn-period|春秋]]才出现**（医缓、医和），理论化要到[[warring-states-period|战国]]（扁鹊四诊）。

**女性穿越者注意**：西周礼教初立但未苛严，女性可主持家事、参与祭祀。风险主要来自战乱与劳役。依托邑中大族、以医织营生，具体对策见[女性穿越者指南](/zh/guides/female-traveler/)。

## 十一、法律与信仰

- **以礼治国**：无成文法，礼即法。"明德慎罚"是口号，刑罚（墨、劓、剕、宫、大辟）依然肉刑当道。
- **信仰**：天命观——"天命靡常，惟德是辅"；祖先祭祀与社稷之礼并行。占卜仍在，但不再是商代那种万事前置。
- **人殉残存**：贵族墓仍有人殉，以俑代人渐成趋势。目睹保持平静即可。
- **列鼎制度**：天子九鼎八簋、诸侯七、卿大夫五、士三或一——**僭越是政治罪**。
- **你的位置**：医、卜皆合法；但"通天"的解释权归王与祝宗卜史，你只做手艺人，不做神职人员。

## 十二、经济与贸易

- **无自由市场**：手工业("百工")为王室与贵族服务，交换以贝币、青铜块与布帛为媒。
- **井田制**：庶人共耕公田、私田纳贡。你的全部农业知识都要通过"助邑中增产"来变现。
- **盐仍是珍品**：盐源地理记忆依旧值钱——教邑人煮盐可换长期庇护。
- **你的交换价值**：医术 > 农技 > 手艺 > 力气。硬通货：贝、铜块、布帛、盐。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 医术（现代知识） | 极高 | 你已具备 |
| 农技（选种、堆肥、休耕） | 高 | 低 |
| 制陶、制骨、编织 | 高 | 中 |
| 农耕 | 中 | 低 |
| 识字（祝史之学） | 低（无处变现） | 高 |

**最优策略**：做"懂医的庶人"——医术让你被邑中需要，农技让你被领主需要。不争身份，只攒不可替代性。等到东周，这些积累会突然升值（见两页 era 页的"上升通道"）。

## 十四、科技水平

- **青铜**：礼乐重器（鼎、簋、编钟）巅峰；失蜡法已现。
- **农业**：仍以木、石、骨农具为主力；休耕制；西周末见块炼铁。
- **天文**：周天子"观象授时"，历法置闰渐精。
- **数学**：筹算成熟。
- **文字**：金文铭记功勋；大篆渐成。
- **交通**：驰道未兴，舟楫与步行为主；"周道如砥"限于干线。

## 十五、现代知识优势

以下是你"知道但西周人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生与消毒**：煮沸、清创、隔离——以"祝由"面目低调变现。
- **农学**：选种、堆肥、休耕轮作——零成本增产，领主的最爱。
- **简易工程**：引水、晾晒、窑炉改良。
- **天象**：西周天文只记录不预测——你的日食预测依旧惊人，但务必包装成"天象示警，宜修德"。
- **数学**：筹算速算，仓库田亩的即战力。
- **严禁炫耀**：礼制议论（僭越之嫌）、冶金（官营）、政治预言（妖言）。
