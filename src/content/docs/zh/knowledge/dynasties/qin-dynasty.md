## 一、时代概览

| 项 | 概况 |
| --- | --- |
| 时间 | 公元前 221 – 前 207 年（战国时的秦国见[[warring-states-period|战国]]页） |
| 地域 | 全境置郡县（三十六郡起），都咸阳 |
| 政体 | 皇帝制 + 三公九卿 + 郡县制，官僚文书行政 |
| 经济 | 盐铁国营；统一半两钱与度量衡；田租口赋徭役沉重 |
| 文字 | 书同文：小篆为官体，秦隶通行于日常 |
| 工程 | 长城、驰道、直道、灵渠、骊山与阿房——刑徒数十万 |

秦王嬴政十年扫灭六国（前 230–前 221），自称"始皇帝"，废分封、行郡县，统一文字、货币、度量衡与车轨。前 213 年焚书、前 212 年坑儒；北击匈奴、南平百越。前 210 年始皇崩于沙丘，前 209 年陈胜吴广大泽乡起义，六国复立；前 207 年子婴降刘邦，秦亡（其后楚汉相争至前 202 年，见未来的汉朝页）。

## 二、穿越前必须知道

- **敌人是国家机器**：编户齐民、什伍连坐、验传（通行凭证）制度——没有户籍和通行证，旅店不敢留你，关津不放你过。商鞅出逃时正是被自己立的法堵死的（"舍人无验者坐之"）。
- **十五年倒计时**：前 221–前 210 是严酷但稳定的秩序期；前 209 起天下大乱。落地年份决定全部策略。
- **焚书，但不烧医书农书**：挟书律焚《诗》《书》百家语，而"医药、卜筮、种树之书"明确不在焚列——**你的知识领域恰好全部合法**。
- **文字已是隶书**：日常文书用秦隶（睡虎地秦简即是），与你认识的汉字已相当接近。识字门槛降到历史最低，识字即可为吏。
- **基础设施空前**：驰道直道贯通全国、灵渠通航、度量衡划一——官道又快又平，但查证也最严。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定落点年份**：秩序期（驰道上文书奔驰、市井用半两钱、狱吏森严）还是崩溃期（陈胜军旗、楚地复国、驰道上跑的是溃兵）？这决定你是"落户"还是"避乱"。
2. **先解决水**：规矩千年不变——**必须煮沸**。
3. **解决衣物**：平民麻衣，快速同化。秦尚黑，但民间并不强制，朴素无标识即可。
4. **最关键的一步——落户而非流浪**：立即进入一个"里"（村落），向里典报到，以"乱后失籍之民"求入籍。在秦代，**主动落籍是生路，被查到无籍是死路**。
5. **不谈来历**：灭国、迁豪富、战乱制造了大量流民——你就是一个"失了户籍的原六国之民"，这是无懈可击的背景。

## 四、第一个月

- **学语言与文字**：官话以秦音为准；文字练秦隶——你认识的今字与隶书一脉相承，练毛笔隶书是出发前就该做的功课。
- **掌握一门官府需要的手艺**：医、农、工。统一帝国正在消化六国，基层官署永远缺技术人员。
- **摸清什伍环境**：你的邻里互相负有告奸义务。不抱怨新政、不收留逃亡者、不与非议朝政者深交。
- **储备过冬**：规矩不变——秋天囤粟囤柴，见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"识字的医者"**：医术加识字，官府与民间都缺你这样的人，且完全合法。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 皇帝 | 始皇帝及其继者 | 不可接触 |
| 三公九卿与郡县官吏 | 官僚系统 | 你们的顶头上司 |
| 有爵者 | 二十等爵（军功授爵） | 供养对象 |
| 士伍 | 无爵平民 | **你的起点身份** |
| 刑徒 | 城旦、舂、髡、钳，数十万 | **严防落入** |
| 私奴婢 | 数量有限 | 避之即可 |

统一之后战事减少，**靠军功上升的窗口基本关闭**——技术（医、农）与文书（书佐、令史）是平民仅剩的两条体面通道。

## 六、语言与交流

- **语言**：官话以秦音为基准，六国故地方言依旧通行。落地先学本地话，再修秦音。
- **文字**：小篆是官体，日常文书用秦隶。**隶书与你认识的汉字已相当接近**——这是全部朝代里识字门槛最低的时刻。
- **文书社会**：产权、纠纷、身份全靠"爰书"（官府笔录）。会写字、会写规范文书的人，任何县寺都抢着要。
- **数字**：算筹与十进制成熟，度量衡已全国统一——你的心算是即战力。
- **可学的基础词**：水、火、食、人、来、去、好、坏——方案不变。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 粟、麦、稻，因地而异；度量衡全国划一 |
| 副食 | 菜羹、豆、腌菜；肉食稀罕 |
| 烹饪 | 蒸煮烤腌——**无炒菜**（铁锅要到宋代） |
| 盐铁 | **官营**——私煮盐、私铸铁器是重罪 |
| 饮水 | **必须煮沸**，工地与刑徒营尤甚 |

**关键生存知识**：被征发者的口粮定额低劣。识别可食野菜（荠、藜、蕨）依旧保命——识别要点见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：平民麻衣（多为本色或皂色），朴素无饰为目标。士以上有冠服等差，勿僭越。
- **住**：必须住在"里"内——里围墙、里门，日落闭门。**野外独居者即盗贼嫌疑**。
- **城市**：咸阳徙天下豪富十二万户，人口冠绝天下；六国故都仍有市肆。
- **寝**：席地而卧，铺垫草席。虱蚤如常——接受它。

## 九、健康与医疗

**国家第一次和你站在同一边——但代价是成为体制的技术人员。**

- **国家医疗已存在**：太医令掌医政；**"疠迁所"强制隔离麻风病人**（睡虎地秦简所载，世界最早的强制隔离制度之一）；《封诊式》已具法医检验规程。你的防疫知识与国家制度同向而行，不再被当作妖术。
- **刑徒营是疫病地狱**：骊山、长城、南越工地人群密集、卫生崩溃。你若不幸被征发，煮沸饮水、隔离病人、处理创面就是自救的全部本钱。
- **卫生变现依旧**：只是身份从"神医"变成"官府离不开的医者"——稳定但不显赫。
- **草药、助产、洁齿**：方案与夏商周三代相同，识别要点见[生存技能实操](/zh/guides/survival-skills/)。
- **心理**：公开行刑（弃市、腰斩乃至族诛）是常见的城市管理手段。目睹时面不改色，是基本的自保——出发前完成脱敏（[心理建设与脱敏](/zh/guides/mental-preparation/)）。

## 十、安全与风险

| 风险 | 等级 | 应对（仅凭知识） |
| --- | --- | --- |
| 无户籍被捕为刑徒 | **致命** | 落地即向里典报到入籍 |
| 徭役征发（戍边、转输、工程） | 高 | 医、工技能身份可缓征；牢记自己"不可替代" |
| 连坐告奸 | 高 | 谨言慎行，履行告奸义务但不出首私仇 |
| 轻罪重罚 | 高 | **出发前背熟秦律红线**（见第十一节） |
| 末年战乱（前 209 后） | 致命 | 判明乱起，避开驰道与关中，向边郡或江东走 |
| 疫病 | 中 | 煮沸、隔离、洁厕——你的主场 |
| 饥荒 | 中 | 野菜识别、储粮 |

**女性穿越者注意**：秦律下女性可立户、可继承嫁资，法律地位不低，但单身无籍女性同样难逃编户罗网。以医、织营生并尽快依附里中人家，具体对策见[女性穿越者指南](/zh/guides/female-traveler/)。

## 十一、法律与信仰

- **法家完全统治**："以法为教，以吏为师"。盗、贼、囚、捕、杂、具诸律细密，肉刑与劳役刑为主，族诛用于大罪。
- **必背的红线**：挟书（私藏《诗》《书》百家语）、偶语诗书（弃市）、以古非今（族）、诽谤妖言（死）、私斗（重罚）、私煮盐铸铁（重罪）、舍匿逃亡者（连坐）。
- **什伍连坐**：五家为伍、十家为什，互相告奸是法定义务——"不告奸者腰斩，告奸者与斩敌首同赏"。
- **信仰**：五德终始，秦为水德尚黑；山川祭祀由官定；方士因始皇求仙而暴贵，又因侯生卢生逃亡引发坑儒——**方士是秦代回报最高、下场最惨的职业**。
- **你的位置**：医、卜在合法名单上（"医药卜筮种树之书"不烧）；但**议论改制即死罪**，你的政治学知识在此无用且致命。

## 十二、经济与贸易

- **半两钱**：全国统一铸币（圆形方孔），中国货币史第一次统一——记住重量与形制，假币劣币一眼可辨。
- **度量衡统一**：尺约 23.1 厘米、斤约 250 克、升约 200 毫升——凭记忆即可做"活体校准器"，市吏与仓吏都愿意用你。
- **盐铁国营**：山泽之利归官。你可以为官府煮盐冶铁（技术人员待遇远好于苦力），不可自营。
- **商业受抑**：重农抑商，市籍管理严格。远途贩运风险大、利润高，但不是你的最优路径。
- **你的交换价值**：医术 > 农技 > 文书会计 > 工匠。硬通货是半两钱、布帛与粟。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 医术（现代知识 + 急救） | 极高（官私通吃且合法） | 你已具备 |
| 书佐 / 令史（识字文书） | 高（各县寺常年缺） | 中（练秦隶即可） |
| 农技（铁犁牛耕、轮作堆肥） | 高（官府劝农） | 中 |
| 工匠 | 中–高（"物勒工名"，责任到人） | 中 |
| 商贩 | 中 | 中（市籍与关卡成本高） |
| 方士 | 爆发式回报 | **极高危**（坑儒警告） |
| 卜筮 | 中（合法但内卷） | 低 |

**最优策略**：做"识字的医者"。医术让你不可替代，识字让你可入县寺为吏——两条腿走路，秩序期安稳升迁；若逢末年之乱，官府身份反成拖累，须及时抽身。

## 十四、科技水平

- **文字**：小篆官体、秦隶日常；简牍文书行政贯通郡县。
- **工程**：驰道网"东穷燕齐，南极吴楚"；直道七百余公里直通九原；灵渠沟通湘江与珠江水系。
- **标准**：统一文字、货币、度量衡、车轨；军工生产"物勒工名"、责任到人。
- **军事**：长城连缀秦赵燕旧塞；弩、戈、铍制式化装备。
- **农业**：铁犁牛耕全面普及，郑国渠灌溉关中。
- **历法**：颛顼历，以十月为岁首。
- **医政**：太医令、疠迁所、《封诊式》——制度化的医疗与检验。

## 十五、现代知识优势

以下是你"知道但秦人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生防疫**：与疠迁所制度同向，推行阻力史上最小。工地防疫、饮水煮沸、创面处理，官府与刑徒都受益。
- **农学**：轮作、堆肥、选种、垄作——在"官府劝农"的体制下，增产即政绩，政绩即赏爵。
- **会计与度量衡**：你的速算与标准记忆，是仓、库、市曹的即战力。
- **急救**：刑徒营与工地永远缺会处理创面、骨折、热损伤的人。
- **地理**：记住驰道、直道、长城与灵渠的走向，你比多数官吏更清楚帝国脉络。
- **严禁炫耀**：议论分封郡县得失（以古非今，族）、预言王朝崩溃（妖言，死）、军工冶金改良（资敌死罪）。你的政治知识在秦代只有一个用途——**闭嘴自保**。
