## 一、时代概览

| 分段 | 时间 | 世界 |
| --- | --- | --- |
| 汉初·文景 | 前 202 – 前 141 | 最友好：轻徭薄赋、开关弛禁 |
| 武帝时代 | 前 141 – 前 87 | 榨取期：盐铁官营、告缗、四十年征伐 |
| 昭宣–哀平 | 前 87 – 公元 8 | 中兴与衰变：昭宣中兴 → 外戚王氏坐大 |
| 新莽 | 9 – 23 | **灾难**：改制与币制双双崩溃，赤眉绿林并起 |
| 东汉盛期 | 25 – 105 | 秩序重建：光武至和帝，佛教初传、造纸改进 |
| 东汉中后期 | 106 – 183 | 疲态：羌乱、党锢、豪强庄园化 |
| 汉末 | 184 – 220 | **地狱**：黄巾、董卓、军阀混战与大疫 |

| 项 | 概况 |
| --- | --- |
| 地域 | 西汉都长安、东汉都洛阳；河西走廊入版图，西域置都护（前 60） |
| 政体 | 皇帝 + 三公九卿（东汉尚书台渐重）；郡县为主，诸侯王国渐被削空 |
| 经济 | 田租三十税一，另有人头税（算赋、口赋）与更役；武帝后盐铁官营 |
| 文字 | 汉隶全盛——与你所识的字一脉相承；东汉末向楷、行演变 |
| 信仰 | 独尊儒术；谶纬盛行（东汉尤甚）；佛教初传、道教萌芽 |

前 202 年刘邦称帝定都长安，"汉承秦制"而罚网放宽：文景之治与民休息，前 154 年平七国之乱；武帝北击匈奴、凿空西域、罢黜百家，也把国家开到榨取极限；昭宣中兴后外戚王氏坐大，公元 9 年王莽代汉，改制与币改双双崩溃；25 年刘秀重建汉室于洛阳，明章以降历羌乱、党锢渐入疲态；184 年黄巾起，大疫与军阀接踵——220 年曹丕代汉，四百年汉室落幕（其后的三国将另有专页）。

## 二、穿越前必须知道

- **四百年 = 七个世界**：同一片土地，文景与汉末的生存策略完全相反。落地第一步永远是"判段"（见第三节），判错满盘皆输。
- **国家仍在，但松了**：编户齐民（"名数"）与关津验"传"依旧，但文帝废肉刑（前 167）、宣帝立"亲亲得相首匿"、流民赦免令常见——这台机器比秦温柔得多，**主动自占名数是正路**。
- **识字第一次等于前程**：察举孝廉、太学博士弟子、郡县文法吏——你的汉字底子（汉隶）可以直接换官做，这是先秦以来没有过的事。
- **医学已成体系，你不是唯一懂医的人**：《黄帝内经》《神农本草经》摆在那里，末年更有张仲景、华佗。你的地盘在外科无菌、防疫检疫、妇产卫生——他们完全空白的领域。
- **商人是政策赌徒**：汉初开关梁、弛山泽之禁；武帝一转脸就算缗告缗（"商贾中家以上大抵破"）、盐铁官营。东汉的自耕农还要面对豪强兼并。
- **汉末（184–220）是全手册顶级难度**：黄巾、董卓、军阀混战叠加连年大疫（张仲景宗族十年死三分之二）。落点在此，先读第十节。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定落点——这一步在汉代比任何朝代都重要**：
   - **看钱**：规整五铢钱 = 汉朝正常期；"货泉""货布"大小错杂 = 新莽；剪边小钱、以谷帛易物 = 乱世（新莽末或汉末）。
   - **听传闻**：都城在西（长安）还是东（洛阳）；匈奴和亲还是单于内附；有无"苍天已死"式的流言（= 184 年前后）；城中有无胡僧佛寺（68 年后渐有）。
   - **问政策热词而非年号**：说"轻田租" = 文景；说"算缗" = 武帝；说"羌乱""党人" = 东汉中后期——交叉验证再定策略。
2. **先解决水**：规矩千年不变——**必须煮沸**。
3. **解决衣物**：平民短褐、犊鼻裈即可。西汉深衣曲裾、东汉直裾袍服——看邻人怎么穿就怎么抄，汉人重衣冠正朔，别露怯。
4. **落户——"自占名数"**：到乡里找啬夫，以"遭乱失籍之民"申报户口。汉代常有流民占名数的赦令，主动申报是正路；被查为"无名数"则罚作刑徒。
5. **不谈来历**：四百年间流民从未断过（灾、役、兼并、战乱）——"逃难的流民"在汉代是最不需要解释的身份。

## 四、第一个月

- **学语言与文字**：通语为主、方言照旧；重点练汉隶，从《急就篇》（汉代识字课本）入手。汉隶与今字一脉相承——这是继秦之后识字门槛最低的时代。
- **摸清乡里权力结构**：三老（教化）、啬夫（税赋诉讼）、游徼（治安），十里一亭置亭长——你的顶头就是这几位。
- **掌握一门营生**：医（补学本地本草）、农（代田、耧车你都能改进）、工（铁器、造纸）。
- **储备过冬**：规矩不变——秋天囤粟囤柴，见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"识字的外科医者"**：识字换前程，外科能救命——两条腿走路的汉朝版。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 皇帝 | 刘氏天子 | 不可接触 |
| 外戚 / 宦官 | 西汉外戚、东汉宦官轮流秉政 | 敬而远之 |
| 官僚 | 察举 / 太学 / 军功 / 赀选出身 | 你的目标圈层 |
| 豪强地主 | 大庄园、部曲徒附（东汉尤盛） | 可依附，勿对立 |
| 编户齐民 | 自耕农 | **你的起点身份** |
| 徒附 / 客 | 庄园依附民，实同农奴 | 东汉破产农民的去处 |
| 奴婢 | 官私奴婢数量可观 | 避之即可 |

**上升通道（先秦以来第一次向平民敞开）**：察举孝廉（东汉定制约二十万口岁举一人）、太学博士弟子（射策考试补吏）、郡县佐吏积功升迁、边郡军功、纳钱谷补官（赀选）。识字 + 一门经学或医术，就能从自耕农走进官吏队伍——这是汉朝给穿越者的最大红利。

## 六、语言与交流

- **语言**："通语"为通用语，方言差异仍大（扬雄《方言》即记各地方言）。先学本地话，再修通语正音。
- **文字**：汉隶全盛；简牍为主、缣帛为贵、麻纸渐用（105 年蔡伦改进后加速）。汉隶就是今字的直系前身——你的读写优势在汉朝达到顶峰。
- **识字生态**：《急就篇》是蒙学课本，许慎《说文解字》（100 年成书）是字典；175 年太学门外立熹平石经，标准经文公开刻石——识字与抄书都有公共资源可用。
- **称谓细节**：汉代习称皇帝为"县官"或天子；新莽禁二名后单名成风（东汉人几乎全是单名）——**给自己取单名**。
- **数字**：算筹 + 《九章算术》已解方程、用负数——但你的十进制笔算速算仍是对算筹的降维打击。
- **可学的基础词**：水、火、食、人、来、去、好、坏——老规矩。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 粟、麦、稻；面食兴起（"汤饼"即面片汤） |
| 副食 | 豆羹、腌菜、菜羹；东汉庄园肉食稍多，平民依旧稀罕 |
| 烹饪 | 蒸、煮、烤、腌——**仍无炒菜**（铁锅要到宋代） |
| 新食材 | 葡萄、苜蓿自西域传入（武帝后）——市面见到即至少前 2 世纪之后 |
| 盐 | 官营但市售常见、价格平稳；私煮盐仍是重罪 |
| 饮水 | **必须煮沸** |

**关键生存知识**：豆腐传说始于淮南王刘安（无确证，别指望）。荒年野菜识别（荠、藜、蕨）依旧是保命技能——识别要点见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：平民短褐、犊鼻裈；士人深衣（西汉曲裾、东汉直裾）渐变为袍。丝绸渐多仍是贵物——你穿麻。合裆裤已普及，不必再受先秦胫衣之苦。
- **住**：夯土墙 + 木构 + 瓦顶在汉代普及，典型民宅"一堂二内"。**东汉的庄园坞堡是乱世最佳避风港**——有墙、有粮、有部曲。
- **城市**：长安九市为西汉之冠；洛阳为东汉都会之首，与邯郸、临淄、宛、成都并称"五都"。市有市楼、市令，市籍管理依旧。
- **寝**：席地而坐、床榻渐高、案几进食；汉末胡床（折叠坐具）才入宫禁。虱蚤如常——接受它。

## 九、健康与医疗

**转变：你从"唯一的医者"变成"懂他们不懂的那一半"。**

- **体系已立**：《黄帝内经》立理论，《神农本草经》收药三百六十五种，淳于意（仓公）已写诊籍（病历）；末年更有张仲景《伤寒杂病论》与华佗的手术、五禽戏——内科与药物学有两千年功力底子，**别在他们强项上逞能**。
- **你的空白区即主场**：外科无菌与清创、骨折复位、防疫检疫（隔离、水源保护、尸体处理）、妇产卫生（洗手、沸煮器械）——汉医完全没有这些，你一出手就是独门。
- **医者地位不低**：太医令掌医政，侍医、民间医皆可体面营生。你的"识字 + 外科"组合在汉朝就业市场是天花板级。
- **红线**：巫蛊是死罪（前 91 年巫蛊之祸牵连死者数万），"妖言"依旧有罪——医术之外，不表演任何"神通"。
- **汉末大疫（171–185 年间数次，217 年大疫）**：张仲景宗族二百余口十年间死三分之二，曹植写"家家有僵尸之痛"。落在末年，你的隔离与检疫知识是救世级的——也是你自己活命的本钱。
- **心理**：公开处刑与乱世暴尸常见，出发前完成脱敏（[心理建设与脱敏](/zh/guides/mental-preparation/)）。

## 十、安全与风险

| 风险 | 等级 | 应对（仅凭知识） |
| --- | --- | --- |
| 落在新莽（9–23） | **致命** | 币制已崩、战火将起——速离两京，早囤粮，依附地方强宗坞堡 |
| 落在汉末（184–220） | **致命** | 防疫优先；远离两京与官道；投坞堡，或 196 年后早入屯田（稳定的饭碗） |

## 十一、法律与信仰

- **罚网放宽**：萧何九章律与令、科、比并行；文帝废肉刑（前 167，缇萦上书）后以徒刑笞刑为主（宫刑残存——司马迁即受此）；秋冬行刑；宣帝立"亲亲得相首匿"，亲属互隐不为罪——比秦人性化一个量级。
- **春秋决狱**："原心定罪"按动机定罪，一句牢骚可以杀头——议论朝政仍需谨慎。
- **必背红线**：私铸钱（五铢是国本）、巫蛊、妖言、伪造图谶、私煮盐。
- **信仰**：独尊儒术后儒学国教化（封禅、明堂、辟雍）；东汉谶纬成"内学"，**妄造谶纬是死罪**；佛教于 68 年立白马寺后渐传，时人视作黄老道术之流；太平道、五斗米道在民间坐大——184 年黄巾即太平道所起，**末年的宗教结社 = 雷区**。
- **你的位置**：医、卜合法且体面；灾异谶纬一概不碰——那是一门"对了没赏、错了杀头"的生意。

## 十二、经济与贸易

- **五铢钱**（前 118 年始铸）：重约 3.2 克，面文"五铢"——此后七百年的标准货币，形制规整、易于辨伪。
- **新莽币制灾难**：五物六名二十八品换来经济崩溃，民间退回以谷帛交易——这也是你判段的硬线索。
- **东汉"谷帛为市"**：布帛的货币职能回升——硬通货是五铢、布帛与粟。
- **盐铁官营与平准均输**（武帝后）：山泽之利归官。你可受雇于官营工场（技术人员待遇远好于苦力），不可自营。
- **告缗之祸的教训**：武帝一朝"商贾中家以上大抵破"——入市籍之前，先看清当朝的政策风向。
- **你的交换价值**：医术 > 农技 > 文书会计 > 工匠。识字在这里直接是商品——代写书信、爰书，教蒙学，都有市场。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 医（外科 / 防疫方向） | 极高（独门空白区） | 你已具备（补学本地本草） |
| 经学 + 文书（察举路线） | 极高（制度化通道） | 中（通一经 + 汉隶 + 《急就篇》） |
| 农技（代田、耧车、区田） | 高（官府劝农） | 低 |
| 工匠（铁器、造纸 105 年后） | 中–高 | 中 |
| 商贩 | 中（政策周期风险大） | 中 |
| 边郡军功 | 中 | 高（生死之赌） |
| 方士 / 谶纬 | 爆发式回报 | **极高危**（妖言 / 私谶死罪） |

**最优策略**：做"识字的外科医者"。秩序期以医立足、以经学文书走察举长线；一旦判明乱世（新莽、184 年后），立即转向——扔掉身份包袱，依附坞堡做防疫医者，活到下一个统一王朝。

## 十四、科技水平

- **造纸**：西汉已有麻纸（放马滩、灞桥），105 年蔡伦改进后渐推广——但简牍仍是主流，纸的胜利要到魏晋。
- **冶铁**：炒钢、百炼钢（"五十湅"钢刀）成熟，31 年杜诗造水排水力鼓风——铁农具、铁兵器全面普及。
- **农业**：代田法（赵过）、三脚耧车、区田法（《氾胜之书》）、牛耕普及；郑国渠旁增开白渠（前 95）。
- **数学**：《九章算术》立方程与负数，《周髀算经》论勾股。
- **天文历法**：太初历（前 104）为第一部有完整记载的历法；张衡造浑天仪，132 年制候风地动仪。
- **医学**：《内经》《神农本草经》定型，末年《伤寒杂病论》开辨证论治之先。
