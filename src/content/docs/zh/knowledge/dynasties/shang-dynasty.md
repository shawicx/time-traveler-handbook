## 一、时代概览

| 项 | 概况 |
| --- | --- |
| 时间 | 约公元前 1600 – 前 1046 年 |
| 地域 | 中原（核心在今河南北部，晚期都城殷即今安阳） |
| 政体 | 王权神授的王国，"内服外服"制（王畿 + 侯伯封国） |
| 经济 | 青铜时代农业 + 王室手工业作坊，海贝行使货币职能 |
| 文字 | **甲骨文**——成熟的汉字体系，但被贞人集团垄断 |
| 金属 | 青铜铸造巅峰：礼器、兵器、车马器，国之重器 |

商由汤灭夏桀而立，中期屡次迁都，盘庚约前 1300 年定都于殷（今安阳），故商又称殷。武丁在位时（约前 1250–前 1192）国势极盛。末王帝辛（纣）于前 1046 年牧野之战败于周武王，商亡。

## 二、穿越前必须知道

- **有文字，但轮不到你用**：甲骨文是占卜档案，识读与契刻由"贞人"（占卜官）垄断。你认识的简化字在这里几乎无用——但汉字功底仍是你的长期资产。
- **人祭是制度，不是事故**：商王室祭祀大量使用人牲，甲骨文可统计的用人祭祀记录逾万，受害者多为战争俘虏（尤其羌人）。**来历不明的外乡人是高危人群**。
- **城市出现了**：晚期都邑"大邑商"（殷）人口以万计，有铸铜、制骨、制陶作坊。你可以"进城"，这是相对夏朝的最大进步。
- **青铜巅峰与你无关**：青铜礼器与兵器是王权与神权的专属。你能接触的手艺是陶、骨、木、麻。
- **酒是国粹，也是国难**：商人上下皆嗜酒，贵族以爵、斝、觚狂饮醴与鬯。保持清醒是你免费的认知优势。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定落点**：看见夯土城墙、成片灰坑、铸铜作坊烟尘，即已入商。远离王陵区与祭祀坑地带——那是流血的地方，不是求助的地方。
2. **先解决水**：直接饮河水会感染寄生虫。**必须煮沸**——借陶器与火种；无陶器则沙坑渗滤或竹节烧水。城内水井亦不可生饮。
3. **解决衣物**：用麻皮、树皮、兽皮尽快裹身。更重要的是**让自己看起来像个当地人**——外表怪异者在商代可能被当作异邦俘虏上报。
4. **依附一个族邑**：以"远方流亡者"身份请求加入城邑中的某个族。投名状依然是**立刻有用的手艺**——修窑、制骨、治一个小伤口。
5. **不要谈论来历，更不要表演"神通"**：占卜解释权归贞人集团。第一天就"预言"什么，等于向王权挑战。

## 四、第一个月

- **学语言**：商语仍属上古汉语，与现代汉语不可互通。第一个月目标是听懂工头指令、说出自己的诉求。
- **掌握一门手艺**：制骨、制陶门槛最低且需求最大（都邑作坊常年缺人）。有一技之长才有饭吃、有族可依。
- **观察权力结构**：分清王与王族、贞人、诸妇、作坊小臣、族长。谁信你，决定你活不活。
- **储备过冬**：中原冬天可达零下，秋天必须囤粟与干肉。封火、草被、防湿的具体做法见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"医"而非"巫"**：商代的"卜、巫、史"高度专业化且排外，外人无从插足。以医术与手艺立足，让效果说话，不要争夺神职解释权。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 王 | 商王，最高军事与祭祀领袖 | 不可接触 |
| 王族与贵族 | 多子族、诸妇、诸子，掌王室权力 | 需取悦 |
| 侯伯 | 地方封国首领（外服） | 尽量远离其征伐 |
| 众人 | 农夫、工匠、牧人 | 你的起点身份 |
| 奴隶与俘虏 | 多为战俘（羌人等），可被用作人牲 | **最高生存威胁** |

**没有"自由旅客"这一身份**。商代人人隶属于某个族，无族者视同奸细或逃奴。你的目标是成为"某族受保护的医者/工匠"，绝非攀附王族——离王越近，离祭祀坑越近。

## 六、语言与交流

- **语言**：上古汉语，声调未定形，语法与现代差异大。手势、模仿、手指计数仍是最可靠的跨语言工具。
- **文字**：**存在但垄断**。甲骨文单字约 4500 个，已释读约三分之一。字形以象形、会意为主——若你有繁体字功底，认读速度将远超本地人。
- **契刻是禁区**：在甲骨上刻字等于冒充贞人，是死罪级别的越界。想识字，先以旁观者身份记诵。
- **干支纪日已通行**：六十甲子循环纪日，商王庙号即用天干（武丁、祖甲、帝辛）。**背熟干支表**是出发前的必修课——能准确"数日子"的人，会被认为通晓天道。
- **可学的基础词**：水、火、食、人、来、去、好、坏（发音不可确证，先记语义）。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 粟、黍为主，麦与稻渐多 |
| 副食 | 猪狗牛羊肉、野菜、豆类；贵族有余，众人匮乏 |
| 烹饪 | 鼎、鬲煮，甗蒸——**无炒菜**（铁锅要到宋代） |
| 饮酒 | 醴（甜酒）、鬯（香酒）泛滥；**克制饮酒**是你的优势 |
| 饮水 | **必须煮沸**，城内水井同样如此 |

**关键生存知识**：商人的粮食安全建立在"众人"的劳作上，歉收之年最饿的也是底层。识别可食野菜（荠、藜、蕨）依然是你的保命技能——形态识别特征与试探程序见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：平民着麻，贵族衣丝。你落地后仍只能就地取材——麻皮、兽皮，用骨针缝制。尽快换成当地麻衣，降低"异类"观感。
- **鞋**：草编或赤足，冬季裹兽皮。
- **住**：都邑内有夯土基址的地面建筑（贵族）与半地穴民居（众人）。争取借住在族邑聚居区，不要独居城外。
- **寝**：铺垫草与兽皮。跳蚤虱子是常态——接受它。

## 九、健康与医疗

**你最大的优势依旧不是药，而是知识。**

- **疾病靠占卜，死亡靠概率**：商人生病先问卜于祖先，"治疗"即祭祀。你的煮沸消毒、伤口清洁、隔离病人能做出他们做不出的"奇迹"。
- **策略：借神道，行医术**：把治愈归功于"按商礼祭祀祖先"，把功劳分给贞人。**与贞人争功是取死之道**。
- **伤口处理**：沸水冲洗，干净（最好经火燎烤）的麻布包扎。不碰粪便、不让伤口触土。
- **草药**：艾草（止血驱虫）、车前草（止泻）、蒲公英（清热）——这是"带脑子"的药箱，识别要点见[生存技能实操](/zh/guides/survival-skills/)。
- **血腥环境的心理损耗**：你将目睹人祭与人殉。若未提前脱敏，惊恐、呕吐、崩溃都会暴露你的异常。出发前完成[心理建设与脱敏](/zh/guides/mental-preparation/)。
- **酒精**：商人酗酒成风，醉酒斗殴与酒精中毒常见。你滴酒不沾或浅酌即止，既是清醒也是护身。
- **分娩与牙病**：洗手助产、沸煮切割工具、柳枝洁齿——与夏朝同理，是你的核心价值筹码。

## 十、安全与风险

| 风险 | 等级 | 应对（仅凭知识） |
| --- | --- | --- |
| 被掳作人牲 | **致命** | 混入当地族群、言行从众、远离祭祀与战争 |
| 战争征发 | 高 | 装病？不行——装病会被占卜。守住工匠身份可免征 |
| 伤口感染 | 致命 | 沸水冲洗 + 清洁包扎 + 隔离 |
| 饥荒 | 高 | 识别可食野菜，储粮，学渔猎 |
| 触怒贞人/贵族 | 致命 | 严守礼仪，医术"归功于祖先" |
| 酗酒斗殴 | 中 | 不饮或浅酌，远离酒宴 |

**女性穿越者注意**：商代女性地位略高于后世（妇好可为将、可主祭），但这是王后与贵族女性的特权。无族属的单身女性面临性暴力、强制配婚乃至被献祭的风险，具体对策见[女性穿越者指南](/zh/guides/female-traveler/)。

## 十一、法律与信仰

- **法律**：无成文法典。裁断依王命、族长与占卜，刑罚严酷（砍足、劓刑、处死）。
- **信仰**：至上神为"帝"，主宰风雨战争；祖先崇拜居于信仰核心——商王通过祭祀与祖先沟通。
- **占卜是一切决策的前置程序**：祭祀、征伐、田猎、生育、疾病，无事不卜。解释权归贞人集团。
- **人祭与人殉**：王室祭祀以战俘为牲，王族葬礼以亲随殉葬。你无力阻止，目睹时保持"习以为常"的表情。
- **禁忌**：不触碰祭器（青铜鼎、爵）与甲骨，不窥视占卜过程，不妄评商王与祖先。
- **你的位置**：以"懂医的工匠"切入，而非"通天的巫"。商代神职的门槛与排他性远高于夏代。

## 十二、经济与贸易

- **货币萌芽**：海贝行使货币职能，以"朋"为单位计数；商王赏贝是莫大荣宠。铜贝（仿贝的铜块）已出现，是金属货币的先声。
- **硬通货**：贝、盐、玉、青铜小件。你无法凭空获得，但手艺与医术皆可换。
- **你的交换价值**：医术 > 手艺 > 力气。治好族长的病，胜过一切实物。
- **盐**：仍是战略物资。若能凭记忆找到盐碱地或盐泉（出发前记住中原盐源地理）并教人煮盐，你在族中的地位将不可动摇。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 制骨（笄、锥、镞） | 高（都邑刚需） | 低 |
| 制陶 | 高 | 中 |
| 编织（麻、草） | 高 | 低 |
| 农耕（粟黍） | 中 | 低 |
| 车马（养马、御车） | 极高（新兴稀缺） | 高 |
| 铸铜 | 极高 | 极高（王室垄断，需引荐） |
| 契刻/书写 | 极高 | **禁区**（贞人垄断） |
| 医术（现代知识） | 极高 | 你已具备 |

**最优策略**：以"制骨或制陶工匠"身份入城吃饭，用医术建立不可替代性，长期再谋车马之术。远离青铜铸造的核心圈——那是王权重地，窥探即罪。

## 十四、科技水平

- **青铜**：陶范法（块范铸造）登峰造极，后母戊鼎重逾 800 公斤。礼器、兵器、车马器俱全。**铸造由王室作坊垄断**。
- **战车**：两轮马车的出现改变战争形态（约当武丁时期传入），双马挽驾，乘员三人（驭手、弓手、戈手）。
- **兵器**：戈、矛、刀、斧、弓矢、青铜胄。
- **文字**：甲骨文（占卜刻辞），另有"册""典"等字表明竹简典册可能并存。
- **历法**：干支纪日连续不断，并有置闰的阴阳合历雏形。
- **农业**：粟黍为主，仍以石、木、骨农具为主力——青铜不下田。
- **手工业**：白陶、原始瓷萌芽、玉器、漆器、丝织。
- **交通**：步行、舟船、马车（贵族与军用）。

## 十五、现代知识优势

以下是你"知道但商人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生与消毒**：煮沸饮水、伤口清洁、隔离病患。能立刻降低族内死亡率，让你被奉为神医——记得把荣誉分给祖先与贞人。
- **基础农业**：轮作、堆肥、选种。粟黍产量可显著提升。
- **简易工程**：引水渠、晾晒架、改进窑炉与骨器作坊的分工流程。
- **天象预测**：日食月食的周期性。**谨慎使用**——一次"预言"可以立威，两次就会与贞人集团正面冲突。
- **干支与算术**：熟背六十甲子与十进制速算，在计日、分派、记账上远超常人，且不触碰占卜禁区。
- **地图与方位**：观星定向、依地势找水找盐。
- **草药识别**：数十种药用植物等于自带药箱。

**严禁炫耀的知识**：冶金（王室机密，泄密即死）、甲骨占卜造假（欺骗神权，处死）、军事技术外流（引发征伐）、政治理念（触怒权贵）。
