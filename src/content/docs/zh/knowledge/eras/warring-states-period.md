## 一、时代概览

| 项 | 概况 |
| --- | --- |
| 时间 | 约公元前 475 – 前 221 年（周王室于前 256 年已亡，此后连名义天子都没有） |
| 格局 | 战国七雄：齐、楚、燕、韩、赵、魏、秦 |
| 政体 | 变法集权：郡县、军功爵、编户齐民、官僚文书 |
| 经济 | 铁犁牛耕普及；鸿沟等水利网；布、刀、圜钱、蚁鼻四大铸币体系 |
| 文字 | 六国古文各异其形；竹简帛书爆炸式增长 |
| 战争 | 总体战：步骑混编、弩机上阵，动辄数十万人 |
| 思想 | 百家争鸣：儒、墨、道、法、名、阴阳、纵横、农…… |

三家分晋（前 403 册命）与田氏代齐（前 386）划定格局；魏用李悝首倡变法，秦用商鞅变法最彻底（前 356）；桂陵（前 354）、马陵（前 342）魏齐易势；合纵连横数十年；赵武灵王胡服骑射（前 307）；乐毅伐齐（前 284）、田单复国（前 279）；长平之战（前 260）赵卒被坑四十余万；前 230–前 221 秦依次灭六国，天下归一。

## 二、穿越前必须知道

- **人头等于田宅**：秦国军功爵"斩一首爵一级"——战争是这个时代最大的上升电梯，也是最快的死法。
- **国家要你的全部**：编户、什伍、征发。商鞅之法的秦国是精密的战争机器，落秦与落齐是两个世界。
- **知识第一次这么值钱**：稷下学宫"不治而议论"而养之，孟尝君食客三千，苏秦身佩六国相印——"朝秦暮楚"不是骂名，是常态。
- **铁与牛喂饱了战争**：生产力暴涨的红利全部投入总体战。丰收的年份意味着下一场更大的战役。
- **国别即命运**：秦（法家极权、军功社会）、齐（学宫自由、商业繁华）、楚（地广贵族传统）、赵（军事革新）、魏（人才输出国）——先背熟五套策略再落地。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定国别**：看货币（布币 = 韩赵魏周、刀币 = 齐燕赵、圜钱 = 秦周、蚁鼻钱 = 楚）、看文字（六国古文五系各异）、看军队（魏武卒重装、赵骑射轻捷、秦军闻战则喜）。判断错国别，策略全错。
2. **先解决水**：规矩不变——**必须煮沸**。
3. **解决衣物**：各国服制不同（赵国已改胡服），快速换成本地常服。
4. **依附**：首选大城市（临淄、邯郸、大梁、郢）投工坊、商肆；若你学识过关，可径投卿相之门为客——**"游学士"是战国最体面的开场白**，没人查你族谱。
5. **不谈来历**：就说"游学四方，闻君侯好士"。这个时代士人跨国流动是常态，来历反而最不被追问。

## 四、第一个月

- **学雅言与所在国文字**：六国文字异形，学哪国字取决于落点；学术与外交语言仍是雅言。
- **选定路线**：技术线（医、农、工——稳）、知识线（学士、辩士——贵而险）、军事线（军功——快而亡）。你的现代知识在三条线上都通，**首选技术线立足，再图知识线进身**。
- **避开征发名册**：编户之下，成年男丁皆在征发之列。医者、工匠、学士有豁免空间——尽快让自己"不可替代"。
- **储备过冬**：规矩不变，见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"游学士 + 医"**：在战国，知识就是身份。你识文断字、通医术、能谈天说地，就是天生的"士"。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 王 | 诸侯僭越称王（前 344 魏惠王首称） | 不可接触 |
| 封君与将相 | 布衣卿相：苏秦、范雎、蔡泽、吕不韦 | **你的理论上限** |
| 士 | 文士、武士、辩士分途 | **你的起点身份** |
| 编户齐民 | 农、工、商，登记在册 | 大多数人的命运 |
| 刑徒与奴婢 | 罪徒、债奴 | 严防落入 |

**战国最伟大的发明是"身份自致"**：出身不再决定终点——白圭为商、扁鹊为医、苏秦佩印、蔺相如宦者令舍人拜上卿。你的全部现代知识都可以在这里定价；代价是，失败者的下场也空前惨烈（商鞅车裂、吴起射杀、苏秦车裂）。

## 六、语言与交流

- **雅言**仍是学术、外交、游说的通用语；民间"言语异声"。
- **六国古文**：齐、楚、燕、三晋、秦五系异形——你学的今字与它们同源不同形，**先学落点国文字**，秦系文字日后回报最大（前 221 年书同文的赢家）。
- **书写工具**：毛笔、竹简，楚地已见帛书。识字者是官署、卿门、商队都抢的人。
- **辩术是你的天赋**：名家"白马非马"、纵横家朝秦暮楚——现代教育的逻辑训练让你天然是个合格的辩士，但**辩术是双刃剑**，说错一句话可能掉脑袋。
- **可学的基础词**：水、火、食、人、来、去、好、坏——老规矩。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 粟、稻、麦、菽并立；铁犁牛耕后产量大增 |
| 副食 | 猪、狗、鸡、鱼；酱、醢、腌菜丰富于前代 |
| 烹饪 | 蒸、煮、烤、腌——**无炒菜**（铁锅要到宋代） |
| 酒 | 民间酿酒普遍，宴饮成风 |
| 饮水 | **必须煮沸**，大城水源污染加重 |

**关键生存知识**：都市场市繁盛带来疫病聚集。野菜识别依旧是荒年保命技能——识别要点见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：深衣大行，各国异制（赵已胡服）；麻为主体、丝为贵。**玉佩与剑是士的标配**——你的"士"人设需要它们，可用医酬置换。
- **住**：大城市人口以十万计——临淄七万户，"车毂击，人肩摩，连衽成帷，举袂成幕，挥汗成雨"。里闾制管理，仍需住在里内。
- **建筑**：高台建筑盛行，瓦当普及，夯土城墙加高加厚。
- **寝**：席地、床榻渐多。虱蚤如常——接受它。

## 九、健康与医疗

**对手是理论化的早期医学——你的优势依旧碾压，且第一次有了合法的职业身份。**

- **扁鹊定四诊**（望闻问切）、立"六不治"，其中一条是"信巫不信医"——**医已与巫公开分家**。你以医为业，名正言顺。
- **战地急救是硬通货**：总体战之下，伤兵以万计。加压止血、夹板固定、清创防感染、烧伤护理——各国军中都缺这样的人。这是最快的晋身之阶，也是把你捆在战争机器上的绳索。
- **城市疫病**：临淄、邯郸级的人口密度是疫病温床。你的流行病学常识（隔离、水源保护、粪便管理）第一次有了真正的用武之地。
- **草药、助产、洁齿**：方案不变，识别要点见[生存技能实操](/zh/guides/survival-skills/)。
- **心理**：坑杀、屠城、灭国是这个时代的日常背景音。长平之后，"天下不乐为秦民"。出发前必须完成对大规模尸骸场景的脱敏（[心理建设与脱敏](/zh/guides/mental-preparation/)）。

## 十、安全与风险

| 风险 | 等级 | 应对（仅凭知识） |
| --- | --- | --- |
| 征发戍战（总体战） | 高 | 医、工、学士身份争取豁免；真被征发，急救技能自保 |
| 连坐酷法（秦系国家） | 高 | 落秦慎之又慎：勿匿籍、勿议法、勿斗 |
| 灭国战乱（前 230–前 221） | 致命 | 统一战争期避开驰道要冲与都城，向齐、楚腹地避祸 |
| 卿相倾轧（变法反噬） | 高 | **做技术客卿，不做权术客卿**——商鞅、吴起的前车之鉴 |
| 城市疫病 | 高 | 煮沸、隔离、水源保护 |
| 伤口感染 | 致命 | 沸水冲洗 + 清洁包扎 |
| 饥荒 | 中 | 野菜识别、储粮 |

**女性穿越者注意**：战国女性可经商、可立户（见诸秦简），医学、织作、货殖皆可营生；但战乱与掳掠的风险高于春秋。依托大城、依托卿门，以医与商立足是最优解，具体对策见[女性穿越者指南](/zh/guides/female-traveler/)。

## 十一、法律与信仰

- **成文法普及**：李悝《法经》为纲，秦律最密；什伍连坐、轻罪重罚（秦系为甚）。
- **礼让位于力**："当今争于气力"是共识。旧礼崩坏，新法冷酷，这是契约与刑罚的时代。
- **信仰**：五德终始说兴起（邹衍），各国争祀山川上帝；民间巫风依旧。**人祭已绝迹**，人殉残存（曾侯乙墓殉二十一女子）。
- **你的位置**：百家争鸣，你甚至可以"自成一家"。但两条铁律：**法家当政之国慎言改制**；**不预言天下归属**（妖言 = 死）。
- **游说红线**：所言不得触及在位者的失势与死亡（借刀者众），不得泄露所事国家的机密（叛国者天下共逐）。

## 十二、经济与贸易

- **四大铸币体系**：布币（三晋周）、刀币（齐燕赵）、圜钱（秦周）、蚁鼻钱与郢爰金版（楚）——**记住币制与成色，落地即可辨国别、防假币**。
- **大工商崛起**：猗顿以盐起家、郭纵以铁成业、白圭"人弃我取，人取我与"——私营工商第一次能积累敌国之富。
- **水利即国力**：鸿沟贯通黄淮、都江堰（前 256）灌沃成都平原、郑国渠（前 246）泽被关中——水利知识是各国争抢的战略资产。
- **盐铁仍是命脉**：齐盐、赵铁、楚金，官私并营。你的盐源地理与冶铁常识可用，但**铁是战略物资，秦地私冶即死**。
- **你的交换价值**：医术 > 农学水利 > 识字文书 > 商术 > 苦力。硬通货：黄金（郢爰）、布币刀币圜钱、粟。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 学士（稷下先生"不治而议论"） | 极高（齐最优渥） | 中（你的知识天然够格） |
| 医术（现代知识 + 战地急救） | 极高 | 你已具备 |
| 农技 / 水利（耕战国策级） | 高 | 中 |
| 兵（军功爵、名将幕府） | 高 | 高危 |
| 商（货殖） | 中–高 | 中 |
| 工（冶、织、漆） | 中–高（官营为主） | 中 |
| 说客 / 纵横 | 极高 | 极高且极危 |

**最优策略**：以医术与农学做**技术型客卿**——被需要、被供养、不被清算。齐国稷下学宫是最安全的落脚点（言论自由、待遇优厚、不问出身）；秦国回报最高但绳索最紧。**做吕不韦的门客，不做商鞅的变法搭档。**

## 十四、科技水平

- **铁器**：铸铁技术持续进步，铁农具全面普及；战国晚期已能处理韧性铸铁。
- **农业**：铁犁牛耕标配；垄作、施肥精细；都江堰、郑国渠、鸿沟水利网。
- **军事**：弩（蹶张、腰引）成建制；步骑混编；长戈、戟、铁剑；各国筑长城。
- **青铜**：曾侯乙编钟（前 433）一钟双音；失蜡法登峰造极（曾侯乙尊盘）。
- **学术**：《墨经》记小孔成像与杠杆原理；甘德、石申编星表（世界最早之一）；二十八宿体系完备。
- **纺织**：楚地提花丝织、漆器工艺巅峰；琉璃（蜻蜓眼）传入自制。
- **编纂**：《吕氏春秋》（前 239）集门客三千之力——知识生产的规模时代。

## 十五、现代知识优势

以下是你"知道但战国人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生防疫**：隔离、水源保护、粪便管理——大城市第一次给了流行病学舞台。
- **农学**：轮作、堆肥、绿肥、选种——"尽地力之教"再加一倍，你是每个变法君主的梦中人。
- **水利原理**：分流、排沙、弯道环流、淤灌——都江堰级智慧可以提前百年落地。
- **战地急救**：止血、固定、清创、烧伤护理——总体战时代的稀缺资源。
- **数学与逻辑**：筹算速算、几何测量、形式逻辑——官署要你，名家服你。
- **天文历法**：甘石之后，你的优势是精度而非独占——以历法家身份合作，勿斗法。
- **严禁炫耀**：弩机与铁冶改良（军工资敌，死罪）、预言天下归属（妖言，死）、法家权术表演（翻车最快——你的下场参考名单很长）。
