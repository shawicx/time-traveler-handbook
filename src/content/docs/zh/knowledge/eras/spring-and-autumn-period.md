## 一、时代概览

| 项 | 概况 |
| --- | --- |
| 时间 | 约公元前 770 – 前 476 年（平王东迁 → 三家分晋前夕） |
| 名义 | 周天子仍是共主，实权在霸主（"礼乐征伐自诸侯出"） |
| 地域 | 黄河、长江流域，诸侯百余，以会盟网络维系秩序 |
| 政体 | 霸主政治：强侯会盟诸侯、"尊王攘夷" |
| 经济 | 井田动摇（前 594 鲁初税亩）；铁器萌芽；空首布初现（晚期） |
| 文字 | 大篆（籀文）；侯马盟书朱墨书 |
| 战争 | 贵族车战，规模有限，受军礼约束 |

前 770 年平王东迁洛邑；前 707 年繻葛之战天子亲征败绩，威信扫地；齐桓公首霸（葵丘之盟，前 651）；晋楚争霸（城濮前 632、邲之战前 597）；前 546 年弭兵之会晋楚平分霸权；吴越相继崛起（前 473 越灭吴）。末年"礼崩乐坏"，三家分晋已在酝酿——落在后三十年，请同步阅读[[warring-states-period|战国]]页。

## 二、穿越前必须知道

- **这是贵族的黄昏，不是平民的黎明**：战争、外交、祭祀是贵族俱乐部，平民是观众和后勤。
- **战争还讲礼**：不鼓不成列、不重伤、不禽二毛——但正在崩坏（前 638 年泓水之战，宋襄公守礼成笑柄）。
- **人口就是国力**：各国招徕流民垦荒，"徕民"是国策。**你天然受欢迎**——这是与战国、秦代最大的不同。
- **上升通道极窄**：世卿世禄。但孔子正在办私学（前 551–前 479），"学而优则仕"的闸门刚裂开一道缝。
- **医与史开始职业化**：医缓（前 581）、医和（前 541）说明"医"已是从占卜中分离的手艺。
- **你什么都没有**：设定不变——落地时只有身体和脑子里的知识。

## 三、前 24 小时

1. **判定国别与年份**：问一句"今孰为伯"（现在谁是霸主）即可大致定年——背熟霸主时间线（见第十六节）。落地国家很关键：齐晋富庶、郑卫工商业发达、楚秦被视为"夷狄"却在上升、宋鲁守礼而弱。
2. **先解决水**：规矩不变——**必须煮沸**。
3. **解决衣物**：上衣下裳、束发右衽，尽快换本地麻衣。周人"被发左衽"即夷狄——发式衣襟就是身份。
4. **依附一个邑**：春秋人口稀缺，以"避乱流民"身份求入邑，邑宰通常乐于收留——你就是税源和兵源。
5. **不谈来历**：说"本国边邑遭了兵灾/戎狄，流亡至此"。没人会细查——这个时代人口流动本就频繁。

## 四、第一个月

- **学雅言与本国方言**：士以上通行雅言。第一个月目标：听懂指令、答问出身。
- **掌握一门营生**：农（各国都缺人）、工（郑、卫手工业发达）、商（郑国商人可与国君立盟，地位特殊）。
- **摸清卿大夫格局**：春秋之患不在国君在卿族——"陪臣执国命"的前夜，别把宝押在一家。
- **储备过冬**：规矩不变，见[古法过冬实操](/zh/guides/winter-survival/)。
- **人设定位——"没落士人之后"**：贵族社会只认"士"层。你识礼、知医、能诵《诗》，就是一个完美的破落士人——比"平民国籍"好用得多。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 天子 | 周王，虚位共主 | 不可接触 |
| 诸侯 | 公侯伯子男，霸主在其中产生 | 选择投靠对象 |
| 卿大夫 | 世卿世家，实权所在 | 真正的天花板 |
| 士 | 文武兼习的最低贵族 | **你的包装身份** |
| 国人 | 城邑居民，有干政传统 | 你的实际起点 |
| 野人 | 乡野耕作者 | 赋役承担者 |
| 奴隶 | 隶臣妾、战俘 | 避之即可 |

**国人干政是春秋特色**：国都居民集体舆论（"国人皆曰可杀"）能左右国政、驱逐国君。你若入城为国人，就有了最低限度的政治人身保障。上升极难，但三条窄缝存在：**军功**（斩获可赏）、**学**（私学萌芽）、**客**（卿大夫养士的雏形）。

## 六、语言与交流

- **语言**：雅言通行于士以上，各国方言差异大。先学本地话，再修雅言。
- **文字**：大篆（籀文），识读仍垄断于祝、史、卜人。识字是你最有价值的"贵族技能"。
- **赋诗言志**：外交与宴飨必引《诗》——你背熟的名句是最快的融入工具，也是"士人"人设的铁证。
- **数字**：算筹通行，你的心算是即战力。
- **可学的基础词**：水、火、食、人、来、去、好、坏——老规矩。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 粟为主，麦、菽渐多，南方有稻 |
| 平民餐 | 豆饭藿羹、粟粥、腌菜；肉食罕至 |
| 烹饪 | 蒸、煮、烤、腌渍——**无炒菜**（铁锅要到宋代） |
| 酒 | 礼有节度，但贵族嗜酒回潮 |
| 饮水 | **必须煮沸** |

**关键生存知识**：荒年依旧致命。识别可食野菜（荠、藜、蕨）是保命技能——识别要点与试探程序见[生存技能实操](/zh/guides/survival-skills/)。

## 八、服饰与居住

- **衣**：上衣下裳，束发右衽；麻为主体、丝为贵。深衣（上下连属）渐起。
- **冠**：士以上加冠，庶人帻巾。你的"士人"人设需要一顶像样的冠——用俸工换。
- **住**：邑有垣墙，夯土宫室为贵族；平民半地穴或地面茅屋。住在邑内，不要独居野外（戎狄与盗贼）。
- **寝**：席地而卧。虱蚤如常——接受它。

## 九、健康与医疗

**医巫正在分离——你恰好站在分界线上。**

- **借"六气"说话**：医和已提出阴、阳、风、雨、晦、明六气致病。用这套话语解释你的消毒与隔离，比"细菌"有效一万倍。
- **卫生知识依旧是神迹**：煮沸饮水、清洁伤口、隔离病患。春秋城市尚小，防疫价值不如战国大，但在军营和邑中依然立竿见影。
- **草药、助产、洁齿**：方案与前代相同，识别要点见[生存技能实操](/zh/guides/survival-skills/)。
- **心理**：这个时代血腥场面相对较少——人祭已废，战争规模有限。会盟歃血、刑戮立威是主要冲击源，脱敏要求低于商与战国。仍建议出发前过一遍[心理建设与脱敏](/zh/guides/mental-preparation/)。

**女性穿越者注意**：春秋婚恋相对自由、再嫁常见、贵族女性可参政（如卫、齐诸媵故事），但战乱中女性仍是最直接的战利品。依托大族、以医织营生是最优解，具体对策见[女性穿越者指南](/zh/guides/female-traveler/)。

## 十一、法律与信仰

- **礼治为主**：刑赏藏于官府，"刑不可知，则威不可测"——前 536 年子产铸刑书才打破传统，引发全国争论。
- **会盟是国际法**：诸侯约信靠盟誓与神明诅咒，背盟者天下共讨——你的国家若背盟，战火会烧到你头上。
- **信仰**：祖先祭祀与社稷为主；占卜仍在但已非万事前置。**人祭已废**，人殉残存（秦穆公前 621 年殉葬一百七十七人）。
- **军礼**：战争的规矩本身就是"法"——不斩来使、不鼓不成列正在瓦解，你无需遵守，但必须能预判对方是否遵守。
- **你的位置**：医、卜合法；私学将兴，"士"的话语体系是你最好的保护色。

## 十二、经济与贸易

- **货币过渡期**：贝币渐退，布帛与粟是主要等价物；春秋晚期空首布（铲形铜币）在晋地出现。
- **商人地位不低**：郑国商人与国君盟誓"尔无我叛，我无强贾"；齐国渔盐之利甲天下。
- **盐仍是硬通货**：你的盐源地理记忆依然值钱。
- **你的交换价值**：医术 > 识字记事 > 农技 > 苦力。硬通货是铜块、布帛、盐、贝。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 医术（现代知识） | 极高 | 你已具备 |
| 识字 / 卜史之学 | 高 | 中（大篆） |
| 商（郑、齐、卫） | 中–高 | 中 |
| 农 | 中 | 低 |
| 武士（车战） | 中 | 高（贵族垄断教练资源） |
| 工（陶、冶、织） | 中 | 中 |

**最优策略**：以"没落士人 + 医术"双身份立足——士人身份让你被贵族社会接纳，医术让你被需要。两者叠加，你可以在任何一个中等诸侯国安身。

## 十四、科技水平

- **铁器萌芽**：前 513 年晋国以铁铸刑鼎；《国语》"美金铸剑戟，恶金铸锄夷"——铁开始下田，但青铜仍是主力。
- **牛耕初现**：晚期渐推（孔门弟子以"牛"为名可见一斑）。
- **青铜**：编钟礼器精绝，失蜡法已现；兵器以戈、戟、剑为主。
- **军事**：车战 + 徒卒；孙武以兵法见吴王阖闾（前 512），兵学理论化。
- **天文**：各国史官连续记录日食；历法置闰渐精。
- **数学**：筹算成熟，工程测量实用化。

## 十五、现代知识优势

以下是你"知道但春秋人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生与消毒**：煮沸、清创、隔离——借"六气"话语落地。
- **农学**：选种、堆肥、垄作——在铁器未普及的条件下，这三样是零成本增产的主力。
- **医学与助产**：洗手助产、沸煮工具——死亡率骤降就是你的口碑。
- **《诗》与礼**：背熟的名句与礼数是你最便宜的通行证。
- **天象**：史官有记录、无预测体系——你的日食预测仍属惊人，但务必用"天象示警，宜修德"包装，勿自称通神。
- **严禁炫耀**：军事献策（会卷入卿族与霸主斗争）、铁冶改良（官营且时机未到）、政治预言。
