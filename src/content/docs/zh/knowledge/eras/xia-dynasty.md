> 本手册遵循核心设定：**穿越者只能本人穿越，赤手空拳，不带任何现代物品。**
> 你唯一的优势，是脑子里的现代知识。本页告诉你如何仅凭这一点活下来。
>
> 夏朝的信史地位至今有争议（二里头文化是否即"夏"仍是学术议题），
> 穿越者应将其视为"早期中原青铜文明"的代名词，而非后世意义的确切王朝。

## 一、时代概览

| 项 | 概况 |
| --- | --- |
| 时间 | 约公元前 2070 – 前 1600 年 |
| 地域 | 中原（今河南西部、山西南部） |
| 政体 | 部落联盟向早期世袭王权过渡 |
| 经济 | 原始农业 + 狩猎采集，物物交换 |
| 文字 | 无成熟文字，仅有刻符 |
| 金属 | 青铜器初现，仅限小件礼器与工具 |

夏朝据传由禹建立，其子启继位，开创"家天下"。考古上对应二里头文化（约前 1900–前 1500），已发现大型宫殿基址与铸铜作坊，但**没有文字实证**。

## 二、穿越前必须知道

- **这不是"古代中国"**：没有汉字、没有皇帝、没有铜钱、没有铁器。你落到的是一个新石器末期的部落社会。
- **你什么都没有**：没有衣服、没有工具、没有药、没有盐。落地时你身上只有自己的身体和脑子里的知识。
- **没有书面信息**：记事靠结绳与刻符，你无法依赖任何文字资料。一切信息只能靠口耳相传与现场观察。
- **季节决定生死**：没有储备农业，冬天可能饿死。如果你能"选择"落地时刻，尽量是春末夏初。
- **青铜极稀缺**：你见到的青铜器比后世黄金还珍贵，是王权象征，不是日用品。

## 三、前 24 小时

1. **判断方位**：找到河流（伊水、洛水），沿水定居点是唯一的文明所在。靠太阳与星星辨别东西南北。
2. **先解决水**：直接饮河水会感染寄生虫。**必须煮沸**——用陶器（村落随处可见）+ 借火种。无陶器则挖沙坑渗滤、或用大竹节烧水。
3. **解决衣物**：落地后尽快用树皮、藤蔓、或剥下的兽皮裹身。冬季裸露几小时即可失温致死。
4. **依附一个氏族**：独行必死。尽快以"远方流亡者"身份请求加入某个村落。你的投名状不是实物，而是**立刻有用的手艺**——帮他们生火、煮水、或治一个小伤口。
5. **不要谈论来历**：任何"我来自未来"的说法都会被当成妖言，可能被处死。你只是一个"远方来的、懂点巫术的怪人"。

## 四、第一个月

- **学语言**：上古汉语与现代汉语不可互通，但基础词汇（水、火、食、人）可逐步掌握。第一个月目标是能听懂指令。
- **掌握一门手艺**：制陶、编织、狩猎是入门门槛最低的。有一技之长才有饭吃。
- **观察权力结构**：弄清谁是氏族首领、谁是祭司、谁是工匠头人。他们的态度决定你的存亡。
- **储备过冬**：秋天必须开始囤积粟、干肉。中原冬天可达零下，无储备会冻饿而死。
- **建立"巫医"人设**：用卫生常识（煮水、隔离病人、伤口清洁）做出几个"奇迹"般的治愈，让氏族把你当成不可替代的神职人员。

## 五、身份与社会地位

| 层级 | 角色 | 你的处境 |
| --- | --- | --- |
| 王 | 禹及其后裔，军事与祭祀领袖 | 不可接触 |
| 贵族 | 各氏族首领，掌地方权力 | 需取悦 |
| 平民 | 农夫、渔猎者、陶工 | 你的起点身份 |
| 奴隶 | 战俘为主，地位极低 | 严防被掳为奴 |

**你没有"自由旅客"的身份选项**。在夏代社会，每个人必须属于某个氏族，否则被视为流寇或奸细。你的目标是快速晋升为"受保护的巫医/工匠"，而不是爬到贵族。

## 六、语言与交流

- **语言**：上古汉语（原始汉藏语），声调系统尚未成形，但语法结构与现代差异大。
- **文字**：**不存在**。不要试图写字交流——没人认识。
- **手势**：跨语言最可靠的沟通方式。指向、模仿、计数（用手指）。
- **可学的基础词**（推测重构，实际发音无法确证）：水、火、食、人、来、去、好、坏。
- **数字**：用手指和脚趾计数，多数部落能理解一到二十。

## 七、食物与饮水

| 类别 | 内容 |
| --- | --- |
| 主食 | 粟（小米）——北方绝对主食 |
| 副食 | 野菜、豆类、少量肉食（猪、狗、鹿） |
| 烹饪 | 陶鼎水煮为主，**无炒菜**（铁锅要到宋代） |
| 饮水 | **必须煮沸**，否则感染寄生虫 |
| 野食 | 识别可食植物是你的生存技能——见下文"知识优势" |

**关键生存知识**：出发前记住中原常见可食野菜（荠、藜、蕨）与毒草的区别。这不是"带东西"，是带脑子。能正确辨认几十种植物，就比 90% 的当地人活得更久。

## 八、服饰与居住

- **衣**：落地后只能就地取材——麻皮、树皮、兽皮。学会用骨针（村落有）缝制简易衣物是第一个月的任务。
- **鞋**：草编或赤足。冬天必须裹兽皮保暖。
- **住**：半地穴式房屋（挖坑搭棚）或地面茅草屋。向村落借住，不要独居野外。
- **寝**：铺草或兽皮，无床。虱子、跳蚤是常态——接受它，不要徒劳抵抗。

## 九、健康与医疗

**这是你最大的优势所在——但不是靠药，是靠知识。**

- **疾病是头号杀手**：夏人没有任何医学。一个小伤口感染即可致命——因为他们不懂清洁。
- **卫生常识即神迹**：煮沸饮水、用沸水清洗伤口、隔离传染病患、焚烧死者。这些"常识"在夏代能让死亡率骤降，你将被奉为神医。
- **伤口处理**：用沸腾过的水冲洗，用干净的（最好烧过的）麻布包扎。不要碰粪便、不要让伤口接触泥土。
- **可用的草药**：出发前记住中原常见药用植物——艾草（止血、驱虫）、车前草（止泻）、蒲公英（清热）。这些是"带脑子"的药箱。
- **分娩**：夏代产妇死亡率极高。若你懂现代助产原则（洗手、剪断脐带用沸煮过的石刀、清洁包扎），这是巨大的价值筹码。
- **牙病**：没有牙医。记住用柳枝嚼细清洁牙齿（古人法），不要嚼硬物崩牙。

| 部落冲突 | 高 | 学会用矛，避免独行，结盟强者 |
| 饥荒 | 高 | 识别可食野菜，储粮，学会渔猎 |
| 毒蛇猛兽 | 中 | 结伴、带火把、识别蛇类 |
| 被掳为奴 | 中 | 守住氏族身份，远离边境 |
| 触怒贵族/祭司 | 致命 | 严格遵守礼仪，不妄言 |

## 十一、法律与信仰

- **法律**：无成文法。纠纷由氏族首领裁决，刑罚严酷（肉刑、流放、处死）。
- **信仰**：万物有灵，祖先崇拜为核心。最高神为"天"或"上帝"（非后世基督教含义）。
- **祭祀**：最神圣的活动。亵渎祭祀场合、亵渎祖先神主，最轻也是流放，通常是处死。
- **禁忌**：不可直视王的祭礼，不可触碰祭器（青铜鼎、玉琮）。
- **你的位置**：以"巫"的身份立足天然契合夏人的信仰体系——他们需要你这样的"通天者"。

## 十二、经济与贸易

- **无货币**：交换以物易物。**海贝**（来自远方海岸）是少数具有一般等价物性质的物品。
- **硬通货**：盐、青铜小件、玉器、海贝。你无法凭空变出这些，但可以通过手艺换取。
- **你的交换价值**：你的劳动力、医术、农事建议本身是可交易的服务。治好首领的病，比任何实物都值钱。
- **盐的获取**：盐是稀缺品。若你能找到盐碱地或盐泉（出发前记住中原盐源地理），并教会族人煮盐，你将成为不可或缺的人。

## 十三、职业与技能

| 技能 | 价值 | 学习难度 |
| --- | --- | --- |
| 制陶 | 高（刚需） | 中 |
| 编织（麻、草） | 高 | 低 |
| 狩猎 | 中（有风险） | 中 |
| 农耕（粟） | 中 | 低 |
| 铸铜 | 极高（稀缺） | 极高（需拜师） |
| 医术（现代知识） | 极高 | 你已具备 |

**最优策略**：以"流亡巫医"身份立足——现代医学知识让你成为稀缺资源，既受保护又难被替代。辅以制陶或编织等基础手艺解决吃饭问题。

## 十四、科技水平

- **青铜**：刚萌芽，仅小件（刀、锥、镜、礼器）。**铸造技术是国家级机密**。
- **铁器**：完全不存在。
- **陶器**：灰陶、黑陶工艺成熟，轮制普及。这是你最容易上手的手艺。
- **玉器**：高规格玉器（圭、璋）是贵族身份与祭祀核心。
- **农业**：粟为主，石镰、骨铲收割。水稻在南方出现，中原罕见。
- **交通**：步行、独木舟。无马车（要到商代）。
- **记事**：结绳、刻符。无文字。

## 十五、现代知识优势

以下是你"知道但夏人不知道"的、可凭空变现的知识（无需任何物品）：

- **卫生与消毒**：煮沸饮水、伤口清洁、隔离病人、焚烧尸体。这能立刻降低死亡率，让你被奉为神医。
- **基础农业**：轮作、堆肥、选种。能让一个村落的粟产量翻倍。
- **简易工程**：引水渠、晾晒架、改进的窑炉。用夏代已有的木石工具即可实现。
- **天象预测**：日食月食的周期性，可强化你"通天"的形象。
- **地图与方位**：观星定向、根据地势判断水源，远超当地人。
- **草药识别**：记住几十种常见药用植物，等于自带药箱。

**严禁炫耀的知识**：冶金（会引发战争）、火药（无意义且危险）、政治理念（会触怒权贵）。
