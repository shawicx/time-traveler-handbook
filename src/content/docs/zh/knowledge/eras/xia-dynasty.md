## 概述

**夏朝**是中华文明传说中的第一个世袭制朝代，约公元前 2070 年至前 1600 年，
据传由禹建立，定都阳城（今河南登封一带）。它处于新石器时代向青铜时代的过渡期，
政治结构为松散的部落联盟向早期王权演进。

## 穿越前必须知道的事

### 你能见到什么

- **青铜器初现**：少量小件青铜工具与礼器，但石器、骨器仍是生产主力。
- **玉器**：高规格的玉器（圭、璋）是贵族身份与祭祀的核心象征。
- **宫城**：二里头遗址显示已有大型宫殿基址，但规模远小于后世皇城。
- **文字**：**没有成熟文字系统**。记事依赖结绳、刻符，穿越者无法依赖书面信息。

### 社会结构

| 层级 | 角色 |
| --- | --- |
| 王 | 禹及其后裔，军事与祭祀领袖 |
| 贵族 | 各氏族首领，掌地方权力 |
| 平民 | 农夫、渔猎者、陶工 |
| 奴隶 | 战俘为主，地位极低 |

### 经济与技术

- **农业**：粟（北方主食）为主，使用石镰、骨铲；水稻在南方已出现。
- **陶器**：灰陶、黑陶工艺成熟，轮制普及。
- **青铜**：仅限小件，铸造技术刚萌芽，铁器完全不存在。
- **货币**：**无金属货币**，交换以物易物或用贝（海贝/骨贝）。

## 生存要点

1. **疾病是最大威胁**：没有医学，一个小伤口感染即可致命。穿越前备好抗生素。
2. **饮食**：粟粥、野菜、少量肉食。烹饪靠陶鼎水煮，无炒菜（铁锅要到宋才普及）。
3. **身份**：你不是贵族就是平民/奴隶，没有"自由旅客"概念。尽快依附某个氏族。
4. **信仰**：万物有灵，祖先崇拜为核心。亵渎祭祀场合可能被处死。
