# 知识库

**时空旅人手册**是一个面向时空旅人的开源知识库。以 Markdown 为唯一数据源，
构建期生成知识图谱、时间轴与科技树，产出完全静态的站点。

选择一个时代进入——人物、事件、技术等会聚合在时代页内部：
