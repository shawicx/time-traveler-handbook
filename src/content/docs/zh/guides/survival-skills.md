# 生存技能实操手册

> 时代指南（如[[xia-dynasty|夏朝]]）告诉你**该会什么**，本篇告诉你**具体怎么做**。
> 你什么都带不了——以下所有技能都只依赖落地后能找到的材料，加上你脑子里的操作记忆。

**先说结论**："知道名字"不等于"会做"。植物名背得再熟，认不出叶子照样没用；
弓钻法原理再懂，手上没有茧就是生不出火。本篇把每个技能拆到可操作的颗粒度，
并在结尾给出出发前的**训练达标标准**。文字只能让你"入门"，出发前必须实操。

## 一、草药与可食植物识别

### 识别三要素

认植物永远靠**形态 + 生境 + 季节**三者互相印证，缺一不可：

1. **形态**：叶序、叶形、叶脉、断面汁液、花果形态——这是主证据。
2. **生境**：每种植物有自己的"家"。车前草长在踩踏过的路边，艾草长在荒坡田埂。
   长错地方的"车前草"是别的东西。
3. **季节**：无花无果时，叶部特征 + 植株高度 + 新芽老茎的组合是关键。

### 药用植物（优先记忆）

| 植物 | 识别特征 | 生境 | 用途（仅凭就地材料） |
| --- | --- | --- | --- |
| 艾草 | 高 50–100cm；叶羽状深裂，**叶背密布灰白绒毛**；揉碎有浓烈特殊香气 | 路旁、田埂、荒坡，成片生长 | 叶捣烂外敷止血；烟熏驱蚊虫；干艾煮水洗皮肤止痒 |
| 车前草 | **贴地莲座状**叶丛，卵形叶有 5–7 条平行弧形脉；花穗细长直立如鼠尾 | 路边、田间、任何被踩过的地方 | 全草煮水温服止轻症腹泻；嫩叶可食 |
| 蒲公英 | 莲座状基生叶倒羽裂；**折断茎叶流白色乳汁**；黄花，谢后成白色绒球 | 田野、路旁、草地 | 全株焯水后可食（味苦）；传统清热用法 |
| 柳树皮 | 乔木或灌木，狭叶垂枝；树皮灰褐有纵裂 | 河岸、水边（也帮你找水） | 树皮煮水含**水杨苷**（阿司匹林前体），退烧镇痛——"古代阿司匹林"，浓煮小杯、过量伤胃 |

**记忆要点**：艾草认"叶背白绒毛 + 香气"，车前草认"贴地 + 平行脉"，蒲公英认"白乳 + 绒球"。
蒿属近缘植物多与艾草用途相近，误认风险低——这正是把它列为首选的原因。

### 可食野菜（中原及北方适用）

| 植物 | 识别特征 | 吃法与警示 |
| --- | --- | --- |
| 荠菜 | 早春贴地羽裂叶，白色小花，**心形短角果** | 全株可食，早春最佳 |
| 藜（灰灰菜） | 嫩叶背面有粉粒感，幼茎常带红条纹 | 焯水后食用；**大量食用后暴晒会光敏中毒**，少量熟食无碍 |
| 马齿苋 | 贴地匍匐，**肉质倒卵形叶**，茎红褐色，味酸 | 可生食可煮食 |
| 蕨菜 | 拳卷状幼叶（"问号"形） | **必须充分煮熟**（含原蕨苷），偶食无碍，不可当主食 |

### 毒物黑名单（认出它们比认药更保命）

- **乌头**：块根像小胡萝卜，蓝紫色盔状花，**全株剧毒**（乌头碱），汁液接触黏膜都危险。
- **蓖麻**：种子有美丽花纹，含蓖麻毒素，**数粒可致命**。
- **钩吻（断肠草）**：缠绕藤本，黄色喇叭状花，全株剧毒。
- **毒芹**：湿生，空心茎带紫斑，植株有腐臭味——**微量即可致命**。

### 铁律

**没有任何一条口诀能可靠区分可食与有毒**（"白色乳汁有毒""颜色鲜艳有毒"都有大量反例）。
只有一条规则：**只吃你 100% 确认的物种**。绝对拿不准时按传统渐进程序试探：
皮肤擦汁液等一刻钟 → 唇角沾少量等一刻钟 → 舌上少量吐出 → 咀嚼吐出 → 吞极少量等 8 小时 →
少量食用等 24 小时，每步无异常才进下一步。**注意：此程序防不了乌头、毒芹这类微量剧毒物，
它只是最后的兜底——确认主义永远优先。**

## 二、生火实操（弓钻法）

### 材料清单（全部就地取材）

- **底板**：干燥轻软木（柳、杨、梓、楸类），约 30cm 长、手掌宽、5cm 厚；
  刻一个指甲状浅凹，凹口边缘开 V 形缺口（让炭粉落下）。
- **钻杆**：直而干的枝条，20–25cm、拇指粗，下端削圆，**最好与底板同种木材**。
- **火弓**：60cm 弹性弯枝 + 麻绳/荻皮/皮条/筋腱。
- **轴承压块**：带凹窝的硬石或硬木块，凹窝涂动物油脂——让摩擦发生在下端而不是手这里。
- **火绒巢**：极干燥的蒲绒、碾碎的干草、朽木粉末（"火绒木"）、桦树皮内层纤维。
- **炭粉接收片**：薄树皮或木片，垫在 V 口下方接炭粉。

### 操作步骤

1. 单膝跪地，**脚踩稳底板**（不稳是一切失败之源）。
2. 弓绳绕钻杆 **1.5–2 圈**，钻杆下端入凹，上端顶入轴承，左手垂直下压。
3. 先慢速短行程拉弓，找准稳定节奏；然后**匀速长行程**，逐渐加下压力。
4. 冒烟后**再坚持 20–30 秒**（加大压力与速度），停下，小心取出底板下的炭粉团。
5. 炭粉倒入火绒巢，合拢轻捏，**先慢后匀地吹气**——见明火后移入引火堆。
6. 引火分级：火绒 → 火柴粗细的细枝 → 铅笔粗 → 手指粗。跳级必灭。

### 失败排查

| 症状 | 原因 |
| --- | --- |
| 烟多不成炭 | 下压力不足，或火绒不够干 |
| 钻杆打滑 | 弓绳松了，重新绕紧 |
| 轴承处冒烟 | 润滑不足——热量错位了，补油脂 |
| 手起泡 | 姿势错误（应垂直下压）——出发前练习长出茧 |

**木材湿度的坑**：雨后一切失败。死树的低枝比地上的落枝干；落地后要在火塘边
主动烘干一套备用生火材料。**现实策略**：古代的火是"保存"出来的（火塘封火，见
[古法过冬实操](/zh/guides/winter-survival/)），族内火种常年不熄。你的价值是
**火种熄灭时能凭空再燃**——这在他们眼里是神迹级技能。

## 三、制陶实操

1. **找土**：河湾、沟壁的沉积黏土层。现场测试：搓成手指粗的泥条绕手指弯曲，
   **不断裂**即可塑性合格。含砂过多时用水搅拌沉降，取上层细浆阴干回可塑状态。
2. **掺和料**：掺 10–20% 的细砂、蚌壳粉或碎陶粒——不掺的陶坯一烧就裂。
3. **成型（盘条法）**：搓泥条一圈圈盘筑，指压抹平接缝，内壁刮密实。无需轮盘。
4. **阴干**：湿布覆盖缓慢阴干数日。**忌暴晒、忌风口**——干太快必裂。
5. **烧成（露天堆烧）**：陶坯先放火边烘干，再围柴堆烧 2–3 小时（堆烧可达 600–900°C）。
   出炉听声：**清脆**是烧透，**沉闷**是欠烧。
6. **失败分析**：爆裂 = 未干透 / 升温过快 / 掺料不足。

**现实策略**：村落制陶是成熟工艺，**跟陶工学远快于自研**。你的增值点是知识——
窑炉改进、渗碳黑陶的原理，懂原理的人跟师一周等于别人跟师一年。

## 四、绳结、制绳与编织

### 制绳（两股反向搓捻）

纤维来源：苎麻/大麻皮层、荻皮、葛藤皮、榆树皮内层、动物筋腱。
浸水捶打分离出纤维后，一手固定绳头，另一手**向同一方向搓捻**两股纤维——
它们会自然绞合成绳。三股编更强。成品绳应能承受你的体重。

### 四个核心绳结（必须练成肌肉记忆）

1. **称人结**（固定圈，承重后仍易解）——口诀"兔出洞，绕树一圈，回洞"：
   绳头自下向上穿出小圈 → 绕到主绳后方 → 从原路穿回小圈 → 收紧。
   用途：套腰救援、任何"需要一个固定圈"的场合。
2. **双套结**（把绳绑到横杆/木桩）——绕杆一整圈压住绳身，再绕一圈从第一圈
   上方穿出，拉紧。两侧受力均衡，是搭晾晒架、绑横梁的主力结。
3. **营钉结**（可调张力）——绕主绳两圈 → 再绕一圈压在前两圈上 → 半扣锁尾。
   可以滑动调整松紧：拉绳、固定庇护所骨架全靠它。
4. **平结**（接两根等粗绳）——"左压右，再右压左"，收紧后两绳头在同侧。
   **致命警告**：两次同向打成"奶奶结"会滑脱；不等粗的绳不要用平结，
   改用接绳结（细绳绕粗绳一圈，绳头从两绳之间穿回压住自身）。

### 编织

- **编筐**：十字排布经条做底 → 纬条穿绕 → 经条弯起立沿继续绕编 → 收口折头插编。
- **编席**：经纬压一挑一，晾晒、铺垫、门帘都用得上。
- **缝皮**：骨针 + 麻线，针脚宜密不宜疏（防风保温的关键在密）。

## 五、出发前训练达标标准

- [ ] 弓钻生火：**连续 10 次尝试成功率 80% 以上**，且在不同天气下试过
- [ ] 绳结：**蒙眼 30 秒内**打出上述 4 个结
- [ ] 植物：实地（植物园/郊野）认过 30 种以上，中原目的地重点过一遍上表
- [ ] 制陶：独立完成一次盘条成型 + 堆烧出成品
- [ ] 制绳：成品绳承受自身体重
